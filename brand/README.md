# Famulen のロゴ

Famulen のアイコンとロゴ、その使い方をまとめる。元になるのは `male/` と `female/` の絵で、ほかのファイルはそこから書き出したものである。

## 二人の秘書

横を向いた秘書の胸像を、暗い地にクリームの一色で描く。丸眼鏡と蝶ネクタイは二人に共通で、`male` は口ひげの執事、`female` は髪をまとめた秘書である。

コンソールのアイコンと、Slack で秘書の発言に付くアイコンは、主人が選んだ秘書の性別に従う。選ぶまでは `male` を使う。二人のどちらか一方だけを見せる所（README など）でも `male` を使う。

## 絵

| ファイル | 用途 |
| --- | --- |
| `avatar.svg`、`avatar-512.png` | 大きく見せる顔。角のない四角の地に、細かい線まで描く。Slack のアイコンに使う |
| `app-icon.svg`、`app-icon-256.png` | アプリアイコン。角丸の地に、小さくても潰れないよう線を減らした絵を置く |
| `favicon-16.png`、`favicon-32.png`、`favicon.ico` | ブラウザのタブ。ごく小さい大きさのために描き直した絵 |

これらは手で描いた元で、書き出しのスクリプトは書き換えない。

## 書き出すもの

| ファイル | 用途 |
| --- | --- |
| `app-icon-192.png`、`app-icon-512.png` | ホーム画面に足したときのアイコン。角丸 |
| `app-icon-square.svg` | 端まで地を塗った四角のアプリアイコン。角を自分で切る所に渡す。丸く切られても絵が欠けない余白を取る |
| `apple-touch-icon.png`（180 px） | iPhone と iPad のホーム画面。四角 |
| `app-icon-maskable-512.png` | Android の、形を端末が決めるアイコン。四角 |
| `mark.svg` | 地のない絵だけのマーク。色は `currentColor` に従い、絵の端まで詰めてある |
| `logo-horizontal.svg`、`logo-vertical.svg` | 明るい背景用の横組みと縦組みのロゴ |
| `logo-horizontal-light.svg`、`logo-vertical-light.svg` | 暗い背景用の横組みと縦組みのロゴ |

`wordmark.svg` は Famulen の文字で、書体は Outfit SemiBold。アウトライン化し、書体のペアカーニングで詰めてある。

絵を差し替えたら、書き出し直す。コンソールが配る分（`frontend/public/icons/`）にも写される。

```sh
nix shell nixpkgs#resvg -c python3 brand/derive.py
```

## ロゴの組み方

マークの高さは、明るい背景では角丸の地の高さ、暗い背景では描かれる範囲の高さとする。

| 組み方 | 決め方 |
| --- | --- |
| 横組み | 文字の高さ（l の上端から並びの線まで）= マークの高さ / φ。文字の上下の中心をマークの中心に揃え、マークと文字の間 = マークの高さ / φ² |
| 縦組み | 文字の幅 = マークの高さ × φ。マークと文字の間 = マークの高さ / φ² |

## 色

| 名前 | 値 | 使う場所 |
| --- | --- | --- |
| 夜 | `#0B0D15` | アイコンの地。明るい背景での文字 |
| クリーム | `#FFF8EB` | 絵。暗い背景での文字 |

## 使ってはいけない形

- 明るい地に、地のないマークを濃い色で置くと、顔が黒く抜けて陰画になる。明るい地では角丸の地ごと使う。一色しか使えない所（刻印など）だけは、`mark.svg` を使ってよい。
- 引き伸ばしたり、傾けたり、左右を返したりしない。
- 絵の中に色を足さない。地の色も替えない。
- 一つの画面で、選ばれた秘書と違うほうを並べない。選ぶための見本は別とする。
- A の字をマークにしない。姉妹のアプリ Arto と Adroit が A の形を使っている。
