# Famulen のロゴ

Famulen のマークとロゴ、その使い方をまとめる。元になるのは `logo/` の SVG で、`png/` はそこから書き出したものである。

## マーク

手帳を抱えた秘書の胸像を、一色の墨で描く。顔は切り抜きで、髪は耳までの長さ、首元は V。手帳は表紙と縦のゴムバンドのある、モレスキンのような手帳で、マークのうち手帳だけを赤にする。頼まれた仕事を手帳に控え、片づくまで抱えている、という Famulen の役を表す。

切り抜きはどれも本当に透けている（マスクで抜いている）。地の色を選ばずに置ける。

100 の枠のうち、描かれる範囲は 18 から 82 である。

既定の秘書のほかに、髪を中央で分けたボブの秘書がある（ファイル名に `woman` が付く）。体つきと手帳は同じで、どちらを使ってもよい。

## ロゴ

ワードマークの書体は Outfit SemiBold で、文字はアウトライン化し、書体のペアカーニングで詰めてある。マークの高さは、描かれる範囲の高さとする。

| 組み方 | 決め方 |
| --- | --- |
| 横組み | 文字の高さ（l の上端から並びの線まで）= マークの高さ / φ。文字の上下の中心をマークの中心に揃え、マークと文字の間 = マークの高さ / φ² |
| 縦組み | 文字の幅 = マークの高さ × φ。マークと文字の間 = マークの高さ / φ² |

## 色

| 名前 | 値 | 使う場所 |
| --- | --- | --- |
| 墨 | `#111111` | マークと文字。アイコンと Slack のアバターの地 |
| 白 | `#ffffff` | 暗い背景でのマークと文字 |
| 赤 | `#c8302c` | 手帳だけ |

まず一色で成り立つように作ってある。赤は手帳を目立たせる飾りで、なくてもマークとして読める。赤のものを既定とし、一色のものも残す。

## ファイル

ファイル名は `famulen[-woman][-red]-<種類>` の形で、`-woman` はボブの秘書、`-red` は手帳が赤のもの。付かないものは耳までの髪の秘書と、一色のもの。

| 種類 | 用途 |
| --- | --- |
| `mark` | マーク（墨） |
| `mark-light` | 暗い背景用のマーク（白） |
| `icon` | アプリアイコン。墨の角丸の地に白のマーク |
| `icon-light` | 角を自分で丸める所（iPhone のホーム画面）に渡すアプリアイコン。白の四角の地に墨のマーク。既定の秘書の赤のものだけがある |
| `avatar` | Slack のアプリと bot のアイコン。墨の四角の地に、Slack が角を丸めても欠けないよう小さめにマークを置く |
| `logo-horizontal`、`logo-horizontal-light` | 横組みロゴ。`-light` は暗い背景用 |
| `logo-vertical`、`logo-vertical-light` | 縦組みロゴ。接尾辞は横組みと同じ |

`png/` には、Slack に上げるアバター（1024 px）とアプリアイコン（512 px）を置く。名前の末尾の数字は幅（px）である。ほかの大きさは `resvg` で書き出す。たとえば `resvg -w 256 logo/famulen-red-icon.svg png/famulen-red-icon-256.png` とする。

`src/` は SVG を作ったスクリプトである。`fontTools` と、`src/fonts/Outfit-SemiBold.ttf`（[Outfit](https://github.com/Outfitio/Outfit-Fonts) の OFL の書体で、リポジトリには入れていない）を用意し、`src/` で `python3 final.py` を流すと `src/final/` に書き出す。

## 使ってはいけない形

- A の字をマークにしない。姉妹のアプリ Arto と Adroit が A の形を使っている。
- マークを引き伸ばしたり、傾けたり、切り抜きを埋めたりしない。
- 手帳以外に色を足さない。手帳も赤か墨のどちらかにする。
