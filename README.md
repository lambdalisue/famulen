# Famulen

一人の主人に仕える、執事や秘書のような AI の補佐役。

> [!NOTE]
> Famulen は作り始めたところで、主人自身が毎日使いながら育てている。目指す姿は [docs/concept.md](docs/concept.md) にある。

できること:

- ブラウザのコンソールで秘書と話す。見ている画面（タブ・期間・選んだ項目）が会話に添えて渡るので、「これ」で通じる。
- 秘書に名前を付ける。コンソールと自己紹介に使われる。
- 予定（Google カレンダーと手帳）・タスク（一度きりと定期、主人と秘書で一つ）・メモ・相手（人・会社・グループ、関係、アカウントの紐付け）・物・契約を、Markdown の手帳に一緒に持つ。物や契約の期限が近づくとタスクに入る。
- 「仕事」「個人」などのワークグループを切り替えると、会話と画面がそこに絞られ、テーマの色が変わる。ワークグループごとに、カレンダーの出し方・使うアカウント・入るサービスを決める。
- Google（Gmail とカレンダー）・Slack・GitHub などのアカウントをいくつでも足せる。一覧にないサービスも、MCP（リモート・ローカル）か API として足す。道具ごとに、まかせる・許可する・確認する・拒否するを決める。確認する道具は、会話の中のカードと Slack のボタンで主人に尋ねる。
- 会話の中の気づきをエピソード記憶に書き留め、夜の夢で心得・長期記憶・保留中の判断に整理する。変更はすべて Git に残る。
- 見張り：届いたメールや Slack の発言、フィードなどをまとめて読み分け、主人に関わるものだけを秘書に渡す。急がないものは朝のまとめに回る。
- 秘書・夢・見張り・トリアージ・見極めに使うモデルを登録して割り当て、一日の上限を決める。使った量はモデルごとに見られる。
- Slack のワークスペースを、秘書と話すチャネルとして足せる（なくても動く）。
- 秘書は起床予約を入れてあとで続きをし、重い仕事は別のエージェントに委託する。

## 使い方

Famulen は、本体（API と秘書のセッション）とコンソール（ブラウザで開く画面）の二つのコンテナで動く。主人が管理するサーバーで、Docker Compose で起動する。

1. リポジトリを取ってくる。

   ```sh
   git clone https://github.com/lambdalisue/famulen
   cd famulen
   ```

2. [.env.sample](.env.sample) を `.env` に写して書く。Google と Slack を使うなら、先に Famulen 用のアプリを一度だけ登録して、その値を入れる。秘書は Claude Code として動くので、`claude setup-token` で作ったトークンと、金庫の鍵も入れる。作り方はどれも [docs/setup/](docs/setup/README.md) にある。
3. 起動する。

   ```sh
   docker compose up -d --build
   ```

4. コンソール（http://127.0.0.1:3000/ ）を開き、左の欄から話しかける。設定の「秘書」の頁で秘書に名前を付ける。
5. 設定の「サービス」で Google などのアカウントと Slack のワークスペースを足す。Slack のワークスペースは、足すと「チャネル」にも並ぶ。夢や見張りに使うモデルは、それぞれの頁で変えられる。

コンソールにログインはない。localhost か、Tailscale などの私的なネットワークにだけ開くこと。外から開くときは https で包み、その URL を `FAMULEN_CONSOLE_URL` に入れる。データは Compose のボリュームに置かれる。設定の詳しいことは [docs/spec/config.md](docs/spec/config.md)。

AI に Famulen を操作させることもできる。コンソールと秘書は同じ API（[proto/](proto/)）を使うので、主人だけに許すもの（道具の権限など）のほかは、コンソールでできることを秘書にも頼める。

## 開発

`nix develop` で開発用のシェルに入る（または `.envrc.sample` を `.envrc` にコピーして `direnv allow`）。そのうえで:

```sh
just dev   # 本体とコンソールを手元で動かす（http://127.0.0.1:3000/）
just fmt   # すべてのソースを整形する
just ci    # CI と同じ確認（整形・lint・テスト・コンソールの型とビルド）
just e2e   # コンソールをブラウザで動かして確かめる
```

目指すものは [docs/concept.md](docs/concept.md)、判断の理由は [docs/adr/](docs/adr/)、約束する振る舞いは [docs/spec/](docs/spec/) にある。
