# コンソールのデザインの提案

コンソールの見た目を作り直すための、見て触れる案。本番のコンソール（`frontend/`）のビルドには入らない。出てくる人・会社・予定・物は、どれも作りものである。

## 見方

`index.html` をブラウザで開く。一枚で完結していて、外には何も読みに行かない。

- 画面は、上のタブ（スマホでは下のタブと「ほか」）で移る。番地でも開ける：`#home`、`#chat`、`#calendar`、`#tasks`、`#delegated`（委託）、`#memos`、`#parties`、`#things`、`#contracts`、`#memory`、`#approvals`（確認）、`#services`、`#look`（表示）、`#threads`（話の見せ方の案を並べたもの）、`#parts`（部品の見本帳）。
- テーマは、上の帯の切り替えか「設定」の「表示」で、システム・ライト・ダークから選ぶ。
- 上の帯の右端の印（PoC の見え方を試す）で、アクセントの色・密度・角丸・見出しの書体・話の見せ方と、スマホ幅での見え方を試せる。この印と見本帳は、本番には持ち込まない。

直すのは `src/` で、`node build.mjs` が `index.html` に綴じる。`node shots.mjs` が `shots/` を撮り直し、同時に検査する（使うブラウザは `frontend/` の Playwright のもの。先に `frontend/` で `pnpm install`）。

## 話（スレッド）を単位にした会話

秘書との会話は、話ごとに別の会話になる。画面では「スレッド」と呼ばず「話」と呼ぶ。本番を作り直す人のために、決めたことと、そのわけを書く。

前提にした決まり（実装中のもので、変わりうる）：話に終わりはなく、いつでも続けられる。題は最初の発言の書き出し。委託の結果・承認の答え・起床予約は、頼んだ話に届く。定期・見張り・つなぎ先の知らせは、一件ごとに一つの話になる。文脈は増えると自動で縮み、発言は消えない。

### 決めたこと

- <strong>話を開いているあいだに書けば、その話の続き。</strong>返信を押さない。一つの発言だけを指したいときは、その発言を引いて返せる（引いたものは札になり、外せる）。どちらでも送り先は開いている話。
- <strong>送り先はいつも入力欄の上に出る。</strong>「続き」と「新しい話」のどちらか、続きなら題も出る。スマホでは、話を開いたときに同じものが出て、畳んだ会話には、いま開いている話の題が出る。時刻で送り先が変わる決まり（最後の発言から何分以内なら続き）は、見えない切り替わりになるので、コンソールの入力欄では使わない。コンソールは、どの話か、または新しい話かを、必ず明示して送る。時刻の決まりは Slack のように送り先を選べない所だけに使う。このため、送る API には「新しい話」を指す値が要る。
- <strong>一覧から書けば新しい話。</strong>前の話を引き継がないことを、その場で伝え、直近の話を続ける道も並べる。
- 書きかけの文は話ごとに残る。ただし、入力欄の上で送り先を替えたときは、文を新しい送り先へ持っていく。書いてから送り先を間違えたと気づく人のため。
- 一覧は、あなたの答え待ち、新しく届いた、今日、以前の順。時刻だけで並べると、待たせているものが沈むため。行には、題、最後の発言と話し手、未読の数、答え待ちの種類（承認待ち、質問、途中で切れた）、結果が届いたこと、動いていること、ワークグループ、どこから来たかが出る。すべて・答え待ち・未読・動いているで絞れる。
- 確認のカードは、尋ねた話の中に出る。確認の一覧と、委ねた仕事の詳細からも、元の話を開ける。
- 結果が届くと、その話が未読になって上がり、入力欄の上に「開く」「あとで」の知らせが一つ出る。読んでいる話は動かさず、画面も勝手に切り替えない。話を開くと、新しいところに「ここから新しい」の線が入り、その話を離れるまで残る。ほかの話に待っているものの数は、戻るボタンに出る。
- 話の頭には題とワークグループと最後に動いた時刻。やりとりの回数、文脈の大きさ、委ねた仕事は、押したときだけ出す。ふだんの判断には要らないため。

### 案を並べたところ

`#threads` に並べ、その場で替えて試せる。

| | 案 | 勧めるもの |
| --- | --- | --- |
| 話の見せ方 | 一覧から入る、一覧を横に置く、一続きに並べて開く | 一覧から入る。スマホと同じ動きになり、読む幅が減らない。話の行き来が多い人には、一覧を横に置くのを設定で選べるとよい |
| 送り先の示し方 | 「続き」「新しい話」の切り替え、題の札 | 切り替え。二つの行き先がどちらもいつも見える |

この画面は、ブラウザで動かして確かめていない。描く関数だけを、にせの DOM で一通り呼んで、綴じの誤りと欠けた値がないことを見た。`shots.mjs` には検査と撮影の段を足してあるが、走らせていない。このため `shots/` の会話は、話を単位にする前のものである。

## 参考にしたもの

コードと画像は写していない。

- Mantine：色の段・半径・影・間隔・文字をトークンで持ち、どの部品も同じ大きさの体系から取る作り。一つの部品に、塗り・薄塗り・枠・透明の変種を揃えること。
- Radix Themes：同じ色に、地・線・塗り・文字の役割を割り当て、ダークを反転でなく別に決めること。
- shadcn/ui：変数を、色の名でなく役割の名（`surface`、`muted`、`accent`）で呼ぶこと。
- Linear：状態を記号の形で見分けさせること、一覧の密度、線の控えめさ。
- Notion：読むところに枠を置かず、本文を組むこと。属性を名前と値の二列で出すこと。

## 方針

### 色

秘書の絵の二色、夜 `#0B0D15` とクリーム `#FFF8EB` から始める。夜は、文字と中立の色の青みになる。クリームは <strong>秘書が書いたものと、秘書が尋ねることの色</strong>で、今日の要約と確認のカードだけに使う。ダークでは文字がクリームになる。

| 役割 | 変数 | ライト | ダーク |
| --- | --- | --- | --- |
| 地 / 面 / 浮いた面 | `bg` / `surface` / `raised` | `#F3F4F7` / `#FFFFFF` / `#FFFFFF` | `#0D0F16` / `#171A24` / `#1F2330` |
| 文字 / 次の文字 / 補足 | `text` / `text-2` / `muted` | `#171A25` / `#434958` / `#5B6172` | `#ECE7DC` / `#C6C4BF` / `#A0A2AC` |
| 線 / 操作の枠 | `line` / `control` | `#DFE2E9` / `#7C8292` | `#2B3040` / `#767D90` |
| 秘書の紙 | `aide` | `#FFFAF0` | `#201E1B` |
| アクセント（深緑） | `accent` | `#14665C` | `#63C2B1` |
| アクセント（夜藍） | `accent` | `#35499A` | `#98A9F2` |
| アクセント（葡萄） | `accent` | `#7A3560` | `#DB9DC2` |
| 情報 | `info` | `#1B5BA7` | `#8DBBF2` |
| 成功 | `ok` | `#23703C` | `#86CF9B` |
| 注意 | `warn` | `#85500A` | `#EBB868` |
| 危険 | `danger` | `#AC2B26` | `#F2998F` |

状態の見せ方：

| 状態 | 記号 | 色 |
| --- | --- | --- |
| 動いている | 回る矢印 | 情報 |
| 順番待ち | 時計 | 中立 |
| 先の仕事を待つ | 錠、破線の枠 | 中立 |
| あなたの答え待ち | 上げた手 | 注意 |
| 済んだ | チェック | 成功 |
| うまくいかなかった | 三角 | 危険 |

アクセントは押せるものと選ばれているもの、ワークグループの色は「いまどこにいるか」だけを示し、混ぜない。

### テーマ

`light-dark()` と `color-scheme` で決める。選ばなければ CSS だけでシステムに従い、端末で替えればその場で替わる。選んだものは `localStorage` の `famulen-theme` に残り、描く前に `<head>` で `data-theme` を付けるので、ちらつかない。開いているほかのタブにも効く。

### 文字

| 使うところ | 大きさ | 行間 |
| --- | --- | --- |
| 見出し | 22px（札や項目の見出しは 17px、15px） | 1.35 |
| 会話・備考などの読み物 | 15px | 1.8、一行は 40 字まで、字間 0.01em |
| 一覧・操作 | 14px | 1.5 |
| 補足 | 13px、12px | 1.5 |
| 等幅（番地、ディレクトリ、差分） | 地の文の 0.93 倍 | 1.5〜1.7 |

書体は端末のもの（ヒラギノ、游ゴシック、Noto Sans JP）。見出しだけを明朝にする案も試せる。スマホの下のタブの名だけは 11px とし、必ず記号を添える。

### 間隔・角丸・影

- 間隔は 4・8・12・16・24・32px。密度は、操作の高さと行の余白を一緒に変える。
- 角丸は操作の 8px を元に、札はその 3/4、カードは 1.5 倍。元の値を変えれば全体が揃って変わる。
- 影は、置いたもの（カード、ボタン）、浮いたもの（入力欄、確認）、重なったもの（モーダル、板）の段だけ。

### 部品

`#parts` に、どれもライトとダークで見られる。

ボタン（主・ふつう・薄塗り・透明・危険、記号だけ、小、待ち、使えない）、入力（文字、長い文、選ぶ、検索、チェック、切り替え、誤り）、カード、確認のカード（外へ送る、質問、仕事を始める、定義の変更、途中で切れた依頼、答え済み）、バッジ、数、チップ、タブ、切り替え、リスト、アバター、進み具合、知らせ、モーダル、板、トースト、スケルトン、空のとき。

### アクセシビリティ

- 文字はどれも 4.5 以上（24px 以上の文字は 3 以上）、操作の枠は 3 以上。`shots.mjs` が、画面・テーマ・アクセントの全部の組み合わせで、描かれた文字と入力の枠ごとに測る。主な組み合わせ（深緑）：

  | 文字と地 | ライト | ダーク |
  | --- | --- | --- |
  | 本文と面 | 17.3 | 14.1 |
  | 補足と面 / 地 | 6.2 / 5.6 | 6.8 / 7.5 |
  | 主なボタンの文字 | 6.8 | 7.8 |
  | 秘書の紙の補足 | 7.0 | 10.1 |
  | 情報・成功・注意・危険の札 | 5.9・5.4・6.1・5.9 | 7.7・8.2・8.4・7.3 |
  | 操作の枠と面 | 3.8 | 4.2 |

- 状態は色だけで示さない。フォーカスはアクセントの 2px の輪で、どの部品でも見える。
- スマホの押せる範囲は 44px 以上。文中のリンクと、カレンダーの予定・グラフの棒は除く。入力欄の文字は 16px で、iPhone が拡大しない。
- `prefers-reduced-motion` では動きを止める。

`shots.mjs` は、ほかに、横へのはみ出し、スクリプトの誤り、外への通信、テーマの追従・保存・ちらつきも確かめる。

## 省いたもの

どれも本番での置き場所は残してある。押すと「PoC なので」と出る。

- 設定のうち、サービスと表示のほかの頁。サービスごとの頁、足すための画面、記録と記憶を書く画面、タイルの並べ替え、カレンダーの日と月。
- ログの頁。秘書の状態の板は開く。
- 会話の読み込みの続き、ファイルを落とす操作、スマホで引いて閉じ開きする操作、滑らせて戻る操作。

## 本番への移し方の案

1. トークンを入れる。いまの変数名に新しい値を割り当て、トークンの外の色を変数に寄せる。ここまでは見た目の差が小さい。
2. テーマを入れる。`light-dark()` と `<head>` の一行、設定の「表示」、`theme-color`。カレンダーとワークグループの、主人が選んだ色は、ダークで明るさを補う。
3. `components/ui/` を、ボタン・入力・バッジ・リスト・カードの順に置き換える。画面の側はほとんど変えない。
4. 会話と確認のカード、次に上の帯とスマホの下の帯。
5. 画面ごとに、タスクと委託、ホーム、記憶、相手、物と契約、設定の順。

どの段も e2e を通し、ライトとダークの画像とコントラストの検査を e2e に加える。

Mantine は React のためのもので、Solid では使えない。トークンと部品の揃え方だけを手本にし、動きのある部品は、いま使っている Ark UI（Solid 版）を続けるのがよい。Kobalte は同じ役割で、載せ替えて得るものが少ない。
