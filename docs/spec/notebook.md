# 手帳の使い方

Famulen は、主人について知っていることのすべてを[手帳](../../crates/notebook/SPEC.md)に置く。手帳は[記憶](memory.md)と[記録](records.md)を持つ。ここには、Famulen が手帳をどう使うかを書く。手帳の形と、手帳を扱うライブラリと CLI は、手帳の仕様のとおり。

## 手帳を用意する

- Famulen を始めると、手帳がなければ作られる。
- 手帳に書く `workgroup` は、Famulen の[ワークグループ](workgroups.md)の ID。
- 主人の記録はすべて手帳に置く。チームの ClickUp のような外のサービスにあるものは、主人の記録ではない。Google のカレンダーにある予定だけは、どのカレンダーかを手帳に書き、見せるときに読む（[カレンダー](calendars.md)）。
- Famulen は手帳をどこへも push しない。ほかのマシンへ渡すのは、主人が[手帳の共有](#手帳の共有)を有効にしているあいだだけ。
- 鍵やトークン、パスワードなどの秘密は手帳に書かず、[ゲートウェイ](gateway.md)の金庫に置く。
- 秘書は道具で、コンソールは API で、手帳の仕様の検索を使って手帳を探せる。

## 手帳の場所

- 手帳の既定の場所は、環境変数か設定ファイルで決まる（[設定](config.md)）。主人は、今の場所を設定の秘書の頁で変えられ、既定の場所にも戻せる。秘書は変えられない。
- 設定で決めた場所は、既定の場所より優先される。既定の場所だけを変えても、Famulen は手帳を移さない。
- 設定で場所を変えると、Famulen は秘書の今の仕事と夢が終わってから起動し直し、手帳を履歴や索引、まだコミットされていない変更ごと新しい場所へ移す。
- 移すのは手帳のファイルだけ。どちらの場所でも、主人のほかのファイルには触れない。新しい場所に手帳のものと同じ名前のファイルがあれば、断る。
- 前の場所の手帳は、新しい場所に写したものと同じだと確かめてから消す。消せずに残ったものがあれば、設定の頁に出る。
- 移せなかったときは、手帳は元の場所のまま使われ、わけが設定の頁に出る。途中で止まったときは、次に起動したときに続ける。
- 手帳の中や、ゲートウェイの置き場所と重なる場所には置けない。
- 設定で決めた場所に手帳がなければ、新しい手帳を作らずに起動をやめる。

## 手帳の共有

ほかのマシンの AI が、同じ手帳を Git で読み書きできるようにする。

- 共有は、主人が設定の秘書の頁で有効にしているあいだだけ働く。はじめは無効で、秘書は変えられない。切り替えはすぐ効く。
- 共有した手帳は、コンソールの URL の下から、Git の HTTP で clone・fetch・push できる。ほかのマシンでは手帳の CLI の[同期](../../crates/notebook/SPEC.md#同期)を使う。
- 共有した手帳に届くのは、コンソールに入れる人と同じ（[コンソール](console.md#どこで開くか)）。出すのは手帳のブランチだけ。
- push は、今の手帳の続きだけを受け取る。履歴の書き換え、ブランチの削除、ほかのブランチ、手帳に置けないもの（symlink、submodule、Git の属性のファイル、`.notebook/`）、大きすぎるものは断る。
- push で変わったファイルが決まりから外れて誤りになるときは、わけとともに断る。前からある別の誤りは妨げない。
- 受け取った変更は、push が済んだときには Famulen の手帳に入っている。まだコミットされていない変更は残り、push がそのファイルに触れるときは断る。
- push でも、手帳の hook や Git の設定は変わらない。
- push を受け取ったことは、秘書のログに残る。

## 書く人と読む人

- 手帳を読み書きできるのは、秘書（会話、夢、取り込み）と主人と、主人が共有した手帳を使う AI だけ。手帳には主人の機密も入る。
- 見張りと手代は手帳を直接読まない。読めるのは、渡されたものだけ。
  - 抜き書き：秘書が手帳から取り出して頼みに書き添えたものと、記録と記憶から作った見張りの[判断の手がかり](lookout.md#読み分け)。
  - 名指したファイル：仕事を委ねるときに、手代に読ませると決めた手帳のファイル。その仕事のあいだだけ読める。
- 変更は、誰がどの入力から変えたかとともに Git のコミットになる。主人が Famulen の外で書き換えたものは、主人のコミットになる。共有した手帳から届いたコミットは、書いた人と trailer のまま残る。
- 主人が Famulen の外で書き換えても、次に読むときに索引が作り直される。

## 決まりどおりかを確かめる

- 手帳が決まりどおりかは、手帳の仕様の「確かめる」で見る。秘書は道具で確かめられ、手帳のファイルを直に書き換えたあとは確かめて直す。
- 主人が Famulen の外で書き換えたものは、主人に断らず直さない。見つけたものは設定の秘書の頁に出て、直し方が一つに決まるものは、主人がそこから直させられる。

## 過去のやりとりから作る

- 主人は、Slack の履歴、メール、AI との過去の会話の書き出しから、手帳を作らせられる。読むのはゲートウェイでつないだアカウントと、主人が渡したファイル。
- 取り込みは古い順に進み、やりとりはその日付のエピソード記憶として書かれ、夢が整理する。記憶の有効な期間は、元のやりとりの日付で決まる。
- 相手は、メールの差出人や Slack のメンバーのように確かな出どころから作る。
- 取り込みで得た記憶は、すべて推し量ったもの（`src=inferred`）になる。心得に入る候補は、入る前に主人が目を通す一覧に出る。
- 取り込むやりとりの文面はそのまま手帳に残さず、そこから分かったことだけを残す。
- 取り込みには[モデル](models.md)の役割と 1 日の上限があり、上限に達すると次の日に続きから進む。コンソールで、どこまで進んだかを見られ、止められる。

## テストで押さえること

- Famulen を始めると、手帳がなければ作られる
- 手帳を移すと、記憶・記録・履歴とまだコミットされていない変更がそろって移る
- 移す前と後のどちらの場所でも、主人のほかのファイルは変わらない
- 移せないときは元の場所の手帳が残り、途中で止まった移動は次の起動で終わる
- 写したあとに変わったファイルは消されない
- 設定で決めた場所の手帳がなくなっていれば、空の手帳で始めない
- 手帳を移すことは秘書の道具にない
- 共有ははじめ無効で、無効のあいだは手帳の Git に届かず、有効にすると clone も push もできる
- 共有の切り替えは秘書の道具にない
- push は今の手帳の続きだけを受け取り、断ったときは手帳が変わらない
- 手帳に置けないものと、新しい誤りになるものの push は、わけとともに断られる
- push は、触れないファイルのまだコミットされていない変更を残し、触れるものは断る
- 手帳の Git からは、手帳のブランチのほかは読めない
- 手帳の誤りは設定の頁に出て、求められるまで直されない
- 秘書は道具で手帳を言葉と絞り込みで探せる
- 見張りと手代からの書き込みは断られる
- 手代は、名指されたファイルのほかは手帳を読めず、仕事が済むと名指したファイルも読めなくなる
- 取り込んだやりとりは、その日付のエピソード記憶になり、古い順に進む
- 取り込みで得た記憶は推し量ったものになり、心得には主人が通したものだけが入る
- 取り込みは上限に達すると止まり、次の日に続きから進む
