# 記録

主人が頼りにする事実。タスク・定期タスク・メモ・予定・相手・物・契約があり、どれも[手帳](notebook.md)を正本とする。主人はコンソールで、秘書は道具で読み書きする。

予定は[カレンダー](calendars.md)に、定期タスクは[定期の仕事と起床予約](schedules.md)に書く。

## どの記録にも通じること

- 記録の書き方は[手帳の仕様](../../crates/notebook/SPEC.md)のとおり。Famulen が使う種類は標準の種類で、`owner` は主人、`secretary` は秘書。
- 記録は、決まった欄のほかに、ワークグループ・ラベル・任意の欄（`Details`）・備考（`Notes`）・経過（`Log`）を持つ。メモは任意の欄・備考・経過の代わりに本文を持つ。
- 開くと、決まった欄・任意の欄・備考・経過と、ほかの記録とのつながりが逆向きも含めて見え、code（`task-7w1hbn` など）も出る。秘書には code でも題名でも通じる。
- どの記録からも、どの種類の記録へもつなげる。備考・本文・経過・任意の欄の文の中にリンクを書くか、「関わるもの」に足す。つながりは片側に足せば両方に見え、その記録に触れている[記憶](memory.md)も見える。
- 備考と本文を書いているとき、主人は記録を選んでリンクを入れられる（`[[` と打っても選べる）。秘書は、触れた記録を code・題名・ID でリンクする。2 件以上に当たる名前なら、どれも選ばず、候補が返る。
- 題名を変えてもリンクは切れず、欄のリンクは今の題名で出る。文の中で主人が付けた別の名前は、そのまま出る。なくなった記録へのリンクは、それと分かるように出る。
- 主人は、備考を何行もの Markdown で書き、ラベルと任意の欄を足し、直し、外せる。
- 備考と本文は、[Arto](https://github.com/arto-app/Arto) と同じに描かれる。手帳の中へのリンクは、その記録を開く。
- 1 件を選ぶと、その 1 件の頁に移る。会話は横に残る。一覧に戻ると、絞り込みと見ていた位置はそのままで、頁からは一覧の前後の 1 件へも移れる。
- 一覧は、言葉・ラベル・ワークグループと、種類ごとの状態や分類で絞れる。
- どの記録も、手帳のファイルの中身をそのまま見られる。

## タスク

- 主人と秘書の仕事は一つの並びにある。誰がやるかは、主人・秘書・相手のどれかで、主人も秘書も切り替えられる。秘書に任せた項目は、秘書がそのまま進める。
- 状態・優先度・始める日・期日を持ち、今日・今週・いつか・済に分かれる。やめたものは済に入る。
- タスクどうしは、親子・ブロックする・関わる、でつなげられる。ブロックされているタスクは、それと分かるように出る。
- [起床予約](schedules.md#起床予約)で待っている秘書の仕事も、タスクの頁に見える。
- 一度きりのタスクと定期タスクは、タスクの頁で切り替えて見る。

## メモ

- 主人が書き留めたこと。主人も秘書も書ける。

## 相手

- 人と、会社・チームと、「キーボード仲間」のようなグループ。
- 相手は名前をいくつも持てる。どの名前でも見つかる。
- 主人との関係も、相手どうしの関係も、それぞれいくつも持てる（部下で友人、二人は夫婦、など）。会社やグループには、属する人とその役目が出る。
- アカウントは、サービスと ID（Slack はワークスペースごとのメンバー ID、メールアドレス、メールのドメイン、X の ID など）。主人か確かな出どころ（連絡先など）で確かめたものと、秘書が推し量っただけのものを分ける。推し量っただけのものは、主人が「同じ人」と答えるまで、やりとりの束ねにも頼みの受け付けにも使わない。
- 相手の頁には、その相手が関わるこれからの予定とタスク、秘書がその相手について覚えていること（[記憶](memory.md)）、最近のやりとりが束ねて出る。
- 人と会社・チームは手で足さず、秘書がやりとりの中で足す。グループは主人も足せる。

## 物と契約

- 物：手元にある物と、手放した物。いつ・どこから・いくらで・なぜ手に入れ、手放したかを持つ。もらった物は、くれた人も持つ。
- 契約：ライセンス・サブスクリプション・回線や保険。提供元・期間・額・払い方と、関わる物を持つ。
- 期限をいくつも持てる。期限の近い順に並ぶ。期限の 2 週間前になると、期限ごとに一度だけタスクになる。手放した物と終わった契約の期限は、タスクにならない。

## 一覧と詳細

- 相手・物・契約は、同じ形の頁で見る。リストとカードを切り替えられる。備考は一覧の列にせず、詳細で読む。

## 夢が整える

[夢](memory.md#夢)は、記憶を整えたあとに、一日に一度、少しだけ記録を整える。主人は設定の夢の頁で止められる。

- することを書いたメモを、主人のタスクにする。メモの本文・ラベル・ワークグループはタスクに入り、同じワークグループに題名が同じでまだ済んでいないタスクがあれば、足さずにそのタスクの経過に本文を書き、ラベルを足す。メモは消えず、そのタスクがあるあいだメモの一覧に出ないだけで、メモへのリンクは開ける。
- しばらく変わっていない記録や、書いてある日付を過ぎた記録を、ほかの記録・記憶・最近の会話と照らす。正しくなさそうなら、古くなったかもしれない印とわけを付け、主人に確かめてもらうタスクを 1 件足す。外のサービスには確かめに行かない。
- 記録に書いてあることは直さず、記録を消さない。書いたばかり・直したばかりの記録、済んだタスク、手放した物、終わった契約、予定、カレンダー、定期タスクには触れない。
- 一晩に見る数と変える数には限りがある。一度見た記録は、しばらく見ない。主人が確かめた記録は、中身が変わるまで尋ね直さない。
- 変えたものとそのわけは、夜ごとの夢の変更に並ぶ。

印の付いた記録は、一覧と詳細でそれと分かり、印のあるものだけに絞れる。主人が印を外すと、確かめるタスクは済になる。秘書は、印のある記録に頼るとき、疑わしいことを伝える。

## テストで押さえること

- 記録にはワークグループの印が付き、複数のワークグループに入れられる
- ワークグループで絞ると、その印が付いた記録だけが出る
- ラベル・状態・分類で絞ると、当てはまる記録だけが出る
- 任意の欄と備考は、コンソールで書いた通りに手帳に残る
- 備考と本文は Markdown として描かれ、中のスクリプトは動かない
- メモと相手のように種類の違う記録も、文の中と「関わるもの」でつながり、両方の頁に出る
- `[[` と打って選んだ記録へのリンクが、書いているところに入る
- 題名を変えた記録は新しい題名で、消した記録はもうないと分かるように出る
- 2 件以上に当たる名前のリンクは、候補とともに断られる
- タスクの担当を切り替えると、秘書の仕事になり、また主人に戻せる
- タスクは今日・今週・いつか・済に分かれる
- ブロックしているタスクが済むか、やめになると、ブロックが解ける
- 自分にたどり着く親子とブロックは断られる
- タスクの頁は、一度きりと定期を切り替えられ、定期タスクはそこで足し、直し、外せる
- 相手は、どの名前でも見つかる
- 片方の相手に書いた関係は、もう一方の頁にも出る
- 推し量っただけのアカウントは、確かめるまで束ねに使われない
- 物と契約は期限の近い順に並ぶ
- 期限の 2 週間前になった物と契約は、タスクになる（期限ごとに一度だけ）
- 手放した物と終わった契約は、タスクにならない
- 秘書は道具で記録を足し、直し、済にできる
- 相手・物・契約は、リストとカードを切り替えられ、選ぶと詳細が開く
- 夢がタスクにしたメモは、本文・ラベル・ワークグループがタスクに入り、メモへのリンクは切れず、次の夜に二つ目のタスクにならない
- 夢が同じ題名のタスクに移したメモも、本文とラベルがタスクに入り、主人の書いた備考は変わらない。ワークグループの違うタスクには移さない
- 古くなったかもしれない記録は、中身が変わらずに印が付き、確かめるタスクが 1 件だけできる
- 主人が印を外すかタスクを済ませた記録は、中身が変わるまで尋ね直されない
- 一晩に変わる記録は、モデルが何と言っても決めた数を超えない
- 夢のあいだに主人が直した記録は、そのまま残る
