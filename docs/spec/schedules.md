# 定期の仕事と起床予約

主人の入力のほかに、定期タスクと起床予約が秘書のターンを始める。

## 定期タスク

- 定期タスクは[記録](records.md)の一つで、手帳に書かれる。持つ欄は[手帳の仕様](../../crates/notebook/SPEC.md#定期タスク)のとおり。時刻は、定期タスクのタイムゾーン、なければ主人のタイムゾーンで読む。
- 主人はコンソールのタスクの頁の「定期」で、足し、直し、止め、消せる。秘書も足せるが、主人が決めたものは変えられない。
- 担当が秘書なら、回が来ると秘書が備考を受けて動く。知らせるに値することがなければ、主人には何も届かない。担当が主人か相手なら、回が来るとその担当のタスクができる。
- Famulen が止まっていて回を何度か逃しても、動き出したときに一度だけ動く。
- 主人は、これからの回を一つずつ飛ばせる。飛ばした回は、来る前なら戻せる。
- 飛ばす条件も付けられる。ほかのタスクがある状態にあるあいだや、前の回がまだ済んでいないあいだ、回は飛ぶ。条件は、回が来たときに見る。条件のタスクが消えているか、条件が読めなければ飛ばさず、経過に残して主人に知らせる。
- 飛んだ回は、わけとともに経過に残る。次の時刻と動いた履歴は Famulen のデータベースが持ち、コンソールで見られる。
- 定期タスクや主人のタイムゾーンを書き換えると、次の時刻が決め直される。変わっていない定期タスクは、動き直しても次の時刻を保つ。

## 起床予約

- 秘書は、時刻か何分後かを決めて、自分あての覚え書きを残せる。その時刻が来ると、覚え書きを受けて動く。
- 起床予約は一度だけ動く。過ぎた時刻には予約できない。
- 秘書は、起床予約にそのわけを添えられる。わけは主人が読むためのもので、時刻が来たときに渡るのは覚え書きだけ。
- 主人はコンソールで、まだ動いていない起床予約を、その時刻と覚え書きとわけとともに見られ、要らなくなったものを取り消せる。取り消した起床予約は動かない。

## テストで押さえること

- いつかは 5 欄の cron で書き、それ以外の書き方は誤りになる
- 時刻は、定期タスクのタイムゾーン、なければ主人のタイムゾーンで読まれる
- 時刻が来た秘書の定期タスクは入力になり、主人の定期タスクはタスクになり、次の時刻へ進む
- 止まっていて逃した回は、一度だけ動く
- 曜日を限った定期タスクは、ほかの曜日には動かない
- 始まりより前と終わりよりあとの回は動かない
- 変わっていない定期タスクは、再起動しても次の時刻を保つ
- 手帳で書き換えた定期タスクは、次の時刻が決め直される
- 秘書は、主人が決めた定期タスクを変えることも消すこともできない
- タイムゾーンを変えると、次の時刻が決め直される
- 飛ばした回だけが動かず、その次の回は動く
- 条件に当てはまるあいだの回は飛び、条件が外れると次の回から動く
- 前の回が済んでいないときに飛ばす定期タスクは、済むまで飛ぶ
- 起床予約は時刻が来たら一度だけ入力になる
- 過ぎた時刻への起床予約は断られる
- 起床予約は、時刻か何分後かのどちらか一方で決める
- 待っている起床予約として見えるのは、まだ動いておらず取り消されてもいないものだけ
- 取り消した起床予約は動かず、もう動いたものは取り消せない
- 入力には、渡した時点の主人の現地時刻が添えられる
