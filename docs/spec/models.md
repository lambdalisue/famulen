# モデル

どの仕事を、どのモデルに、いくらまでで任せるか。

## 使えるモデル

このマシンで使えるモデルは、Famulen が見つけて自動で登録する。それ以外のモデルは主人が登録する。種類は次のとおり。

| 種類 | 例 | 呼び方 |
| --- | --- | --- |
| エージェント CLI | Claude Code、Codex | 実行ファイルとモデル名。道具を使ってターンを回せる |
| ローカル | Ollama | OpenAI 互換の口の URL とモデル名 |
| API | 従量課金のサービス | OpenAI 互換の口の URL、鍵、モデル名、値段 |
| 判定 API | Jev、OpenAI Decisions API | 決めた選択肢から選ぶだけの口の URL、鍵、値段 |
| 文字起こし | whisper | OpenAI 互換の文字起こしの口の URL |

- 値段は、入力と出力の 100 万トークンあたりか、1 回あたりで入れる。定額のものは値段を入れない。
- 鍵は[金庫](gateway.md#金庫)に置かれ、呼ぶときにゲートウェイが付ける。頁には鍵が金庫にあることだけが出る。
- モデルを登録するのは主人だけで、秘書の道具にはない。
- 登録したモデルの頁の「モデルの追加」では、足し方を選ぶと、それに要るものだけを尋ねる。よく使うサービスを選べば URL は埋まり、ローカルのサーバーでは、そのサーバーにあるモデルから選べる。
- 役割が使っているモデルは外せない。

### 自動の登録

- 自動で登録するのは、ログインしてある Claude Code と Codex が使えると答えるモデルと、このマシンの Ollama にあるモデル。起動したときとそのあと定期的に、また主人が「探し直す」を押したときに見直す。
- 主人が外したモデルは、主人が「モデルの追加」から戻すまで自動では登録されない。
- なくなったモデルは一覧から外れる。役割が使っているものは残る。
- Claude Code や Codex や Ollama に尋ねられないときは、そこから登録したものをそのまま残す。
- 自動の登録が、役割の割り当てや主人が自分で登録したモデルを変えることはない。

## 役割

| 役割 | 割り当てられる種類 | 最初のモデル | 最初の考える深さ |
| --- | --- | --- | --- |
| 秘書 | エージェント CLI（Claude Code だけ） | Claude（Sonnet） | ふつう |
| 夢 | エージェント CLI・ローカル・API | Claude（Opus） | とても深い |
| 見張り | エージェント CLI・ローカル・API | Claude（Haiku） | ふつう |
| トリアージ | 判定 API・エージェント CLI・ローカル・API | Claude（Haiku） | 浅い |
| 見極め | エージェント CLI・ローカル・API | Claude（Haiku） | 浅い |
| 手代 | エージェント CLI | なし（秘書と同じモデル） | なし |
| 取り込み | エージェント CLI・ローカル・API | なし | なし |
| 声の聞き取り | 文字起こし | なし | なし |

声の聞き取りは、声で話しかけるチャネル（Even G2 など）のための役割で、そのチャネルができるまでは画面に出さない。

- 最初に起動したとき、上の表のとおりに割り当てる。役割が増えたときは、増えた役割にだけ一度割り当てる。主人が変えた割り当てを戻すことはない。
- 主人は、役割のモデルと 1 日の上限を、コンソールのその役の頁で選ぶ。モデルの頁には、登録したモデルと、それぞれを使っている役割が出る。
- 上限は、値段のあるモデルは円で、ないモデルは回数で決める。
- 上限に達した役割は、その日のそれ以上モデルを使わない。止まっているあいだどうなるかは、[夢](memory.md#夢)・[見張り](lookout.md#読み分け)・[トリアージ](channels.md#注視)・[手代](worker.md#結果)・[取り込み](notebook.md#過去のやりとりから作る)・[見極め](tool-permissions.md#自動)に書く。秘書の上限は会話を止めない。
- エージェント CLI を選んだ役割には、考える深さ（浅い・ふつう・深い・とても深い・最大）も決められる。「既定に戻す」で、最初の深さに戻る。深さを持たない割り当てはモデルの既定で考える。秘書の深さは、いま進めている仕事が終わってから効く。

## 使った量

- 呼び出しのたびに、役割、モデル、入出力のトークン（分かるとき）、回数、見積もりの額を記録する。
- コンソールの「使った量」で、週・月・年のどれかの期間を選び、前後の期間へ移って見られる。週と月は日ごと、年は月ごとの推移になる。日と月は主人のタイムゾーンで区切る。
- 推移と合計は、エージェントごとにも、モデルごとにも見られる。推移のうち一日（年なら一月）を選ぶと、その間の回数・入出力のトークン・額を見られる。
- 値段のあるモデルは額で、ないモデルは回数で推移を見る。二つを一つの図に混ぜない。モデルに値段があったときの額は、登録を外したあとも額で数える。
- 定額のモデルの月額は、主人が入れた値を、従量課金の額とは分けて出す。

## テストで押さえること

- 秘書にはエージェント CLI の Claude Code だけが割り当てられる
- 役割に割り当てられない種類は断られる
- 呼び出しは使った量として記録され、値段から額が見積もられる
- 上限に達した役割は、それ以上呼ばれない
- 考える深さは役割ごとに割り当てと一緒に残り、エージェント CLI のときだけ渡る
- 日と月は主人のタイムゾーンで区切られ、過ぎた期間にはそのあとの呼び出しが入らない
- 量は、区切りごとに、役割とモデルの組で足される
- 値段のあるモデルとないモデルは、登録を外したあとも分けて数えられる
