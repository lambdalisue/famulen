# ゲートウェイの使い方

Famulen は、外のサービスとのやりとりを[ゲートウェイ](../../crates/gateway/SPEC.md)に任せる。つなぎ先・権限・金庫・呼び出しの控えはゲートウェイが持ち、ゲートウェイの仕様のとおりに振る舞う。ここには、Famulen がゲートウェイをどう使うかを書く。

## 持ち主と呼ぶ者

ゲートウェイの持ち主は主人。Famulen の中の役は、次の呼ぶ者としてゲートウェイを呼ぶ。

| 呼ぶ者 | 付与 |
| --- | --- |
| 秘書 | Adroit のセッションを始めるものと再開するもののほかの、すべてのつなぎ先の、すべての道具 |
| 手代 | 委ねるときに渡した道具だけ。確認の権限の道具は含まない |
| 手代の詰所（手代の名で呼ぶ） | Adroit のセッションを始め、その様子を読むことだけ |
| 見張り・トリアージ・夢 | なし。モデルはゲートウェイの道具を呼ばない |
| 見極め | なし。自動の権限の呼び出しを、呼ぶ者に代わって判断するだけで、自分では呼ばない |
| 主人本人 | すべて。コンソールの操作と、主人が組んだ仕組みの呼び出し |

チャネルの返事と確認の投稿、見張りとカレンダーの読み出し、知らせの頼み直しは、主人が組んだ仕組みとして主人本人として呼ぶ。禁止の権限の道具は、これらでも呼べない。

呼び出しの裁き方と、主人への尋ね方は[道具の権限](tool-permissions.md)のとおり。

## 秘書のモデル CLI に渡すもの

- モデル CLI には、Famulen の道具の口だけを MCP で渡す。つなぎ先は、つなぎ先ごとに 1 つの MCP サーバーとして渡し、その答えはゲートウェイが返す。道具の名前は `mcp__<つなぎ先>__<道具>` になる。
- モデル CLI には、外の MCP サーバーの居場所も秘密も渡さない。モデル CLI がほかの設定の MCP サーバーや claude.ai のコネクタを読み込むことはない。
- モデルを差し替えても、外の道具は同じ名前で同じように使える。

## 受け口と宛先

ゲートウェイは届いたものに手を加えずに渡す。何が届いたかを読むのは、宛先にした Famulen の部品。宛先は、チャネル・見張り・カレンダー・秘書のどれか。

| 宛先 | 届いたもの |
| --- | --- |
| [チャネル](channels.md) | Slack の出来事 |
| [見張り](lookout.md) | Google のメールの知らせと、宛先の勧めのない受け口に届いたもの |
| [カレンダー](calendars.md) | Google のカレンダーの変化の知らせ |
| [秘書](secretary.md) | 待たずに主人に伝えるべき知らせ（主人を待つ Adroit のセッションなど）。サービス定義の添え書きとともに、見張りを通らず秘書の入力になる |

- 主人がまだ選んでいない受け口は、サービス定義が勧める宛先に渡し、勧めがなければ見張りに渡す。どの受け口も、主人がつなぎ先の頁で宛先を選び直せる。どこにも渡さないと選んだ受け口は閉じ、Famulen が既定の宛先に戻すことはない。選び直したことは、主人のものとしてゲートウェイの控えに残る。
- つなぎ先を足すと、Famulen を動かし直さなくても受け始める。
- Google のアカウントは、1 回のログインで、メールとカレンダーの両方の受け口を持つ。メールの知らせはアカウントに Pub/Sub のトピックがあるとき、カレンダーの知らせは `FAMULEN_RECEIVE_URL` と知らせの合言葉があるときに、Famulen がゲートウェイの道具で Google に頼んでおく。期限があるので、期限の前に頼み直す。
- 知らせを受けたのに読めなかったメールは、あとで前に読んだところから読み直す。
- 受け口に外から届くようにするか（Tailscale Funnel やリバースプロキシなど）は、主人が決める。届かないときは、カレンダーは決まった間隔で読み直す。
- Slack と Gmail の受け方は、どちらもゲートウェイから外へ張る接続なので、受け口に外から届かなくても使える。

## つなぎ先の足し方

- つなぎ先は、コンソールのサービスの頁の「サービスを足す」で開くダイアログから足す。ダイアログでは、ゲートウェイが読んだサービス定義と、よく使うサービス（Notion など）を、名前や何に使うかで探せる。選ぶと、要る欄があれば尋ね、ログインの要るものはログインの画面に進む。入れた鍵と環境変数の値は金庫に入る。
- 一覧にないサービスは、そのサービスの説明にある URL・コマンド・設定（ほかの AI アプリに入れる JSON や `claude mcp add` の行）を貼って足す。リモートの MCP サーバー・このマシンで動かす MCP サーバー・API のどれかは、貼ったものから読み取る。説明が読み手に任せた値（`<your token>` など）は、空の欄になる。
- ログインに登録したアプリが要るサービスは、アプリがなければ、選んだときに登録の手順を示す。
- MCP でつないだサービスも、サーバーかログインの相手が教えるなら、誰でつながっているかをアカウントとして出す。MCP のアカウントは見分けるための目印で、主人が書き換えられる。書き換えても、つながるアカウントは変わらない。
- サービスの頁には、つないだものだけが並び、名前とアカウントで探せる。
- 読めなかったサービス定義は、そのわけとともにダイアログに出る。
- ログインを済ませずに残ったつなぎ先は「ログイン待ち」として一覧に残り、ログインを続けるか外せる。

## 同梱のサービス定義

ゲートウェイが同梱するサービス定義の、足すときに要るものと使い方は、それぞれの手順に書く。

- [Adroit](../../crates/gateway/services/adroit/README.md)：[下](#adroit)のとおり。
- [Bluesky](../../crates/gateway/services/bluesky/README.md)：ハンドルとアプリパスワードを尋ねる。
- [Discord](../../crates/gateway/services/discord/README.md)：bot の鍵を尋ねる。
- [GitHub](../../crates/gateway/services/github/README.md)：アカウントごとにログインする。道具は GitHub の MCP サーバーのもので、通知は見張りに足せる。
- [Google](../../crates/gateway/services/google/README.md)：アカウントごとにログインする。つなぐと、その主のカレンダーがカレンダーに、受信箱が見張りに入る。
- [KING OF TIME](../../crates/gateway/services/kingoftime/README.md)：会社のアクセストークンを尋ねる。
- [kintone](../../crates/gateway/services/kintone/README.md)：Cybozu の MCP サーバーを Famulen を動かすマシンで動かす。
- [RSS](../../crates/gateway/services/rss/README.md)：公開のフィードの URL を尋ねる。1 つのフィードが 1 つのつなぎ先になる。
- [Slack](../../crates/gateway/services/slack/README.md)：ワークスペースごとにログインする。秘書の bot と主人のアカウントの両方でつながり、[チャネル](channels.md#slack-のワークスペース)に並ぶ。

### Adroit

- ログインも鍵もなしに足せる。
- 秘書は、主人の Adroit に Claude Code や Codex のセッションを開いて、Famulen 自身やほかのプロジェクトの仕事をさせるよう[委ねられる](worker.md)。始めるたびに、タスク・ディレクトリ・頼みを添えて主人に確認する。
- 秘書は、主人が始めたものも含めて、セッションの一覧・様子・やりとり・変えたファイル、プロファイルと利用枠の残りを読める。
- 続きを頼む、止める、終えるときも、主人に確認する。終わったものを再開するのは主人で、秘書にはできない。続きは、主人の言葉ではなく Famulen からの依頼として届く。
- 主人を待つセッションは、秘書に直に届く。主人が Adroit を見ていなければすぐ、見ているあいだはしばらく待ったままのときにだけ届く。秘書は、どの仕事が、どこまで進んで、何を尋ねているかを主人に伝えて答えを聞く。
- 主人が Adroit で答えたら、まだ読まれていない知らせは届かず、出した確認は取り下げられ、Slack の知らせにはもう要らないことが書き足される。
- 許可・計画・質問への答えも秘書が届けられる。答えるたびに問いの原文を主人に見せ、主人が承認か却下をしたもの、質問なら主人が選ぶか書いた答えだけが届く。質問への答えを改めて承認することはない。この答えは、どの権限を選んでも尋ねずには行われない。
- 終わったセッションのことは見張りに届く。委ねたセッションなら、見張りではなく委ねた仕事の終わりとして秘書に届く。
- 答える・止める・終えるには、主人が Adroit で作って入れた鍵が要る。

## つなぎ先の頁

つなぎ先の頁には、つなぎ先の一つひとつについて、Famulen とのつながりのすべてが出る。そのつなぎ先にないものは出ない。

- つながり：名前・アカウント・つなぎ方・状態・種類（権限の既定を引き継ぐ単位）・入るワークグループ、ログインし直す、外す。
- アカウントの値：入れ直せる。定義が秘密とした欄は金庫に入り、頁には入っているかだけが出る。ログインで分かった値は、そのまま見られる。
- チャネル：そこで話しかけを受けるか（[チャネル](channels.md)）。
- カレンダー：Google のアカウントのカレンダーの一覧と、足す・外す・読み直す（[カレンダー](calendars.md)）。
- 見張り：そのつなぎ先を見る見張りごとに、動かすかと、まとめて見る間隔（[見張り](lookout.md)）。
- 受け口：チャネルでない受け口ごとの宛先。
- 道具：道具の一覧と権限（[道具の権限](tool-permissions.md)）。

## 金庫

金庫に何が入り、誰に何が見えるかは[ゲートウェイの仕様](../../crates/gateway/SPEC.md#金庫)のとおり。

- 主人は、コンソールの設定の金庫の頁で、秘密を足し、置き換え、説明を直し、消す。秘書も、道具で同じことができる。どちらも中身は読めない。
- 秘書が秘密を入れる・説明を直す・消すときに主人に尋ねるかは、金庫の頁で主人が決める。既定は、入れるのと説明を直すのは尋ねず、消すのは尋ねる。主人が「まかせる」を選ぶと、いずれも尋ねる。尋ねているあいだ、入れようとした秘密は金庫に封じられ、確認には名前だけが出る。
- 金庫の頁は、主人や秘書が足した秘密と、ログイン・つなぎ先の鍵・モデルの登録のときにゲートウェイが自動で入れた秘密を分けて並べる。自動で入った秘密には、どのつなぎ先やモデルのものかが出る。
- 秘書が会話や手帳の中に秘密を見つけたら、金庫に移して元から消す。秘書が金庫に渡した秘密は、Famulen の記録にも残らない。
- モデルの鍵は、モデルの頁からも金庫の頁からも置き換えられるが、金庫の頁からは消せない。モデルを外すと鍵も消える。モデルの API を呼ぶたびに、どの役の呼び出しかがゲートウェイの控えに残る。
- 見張りと手代を含め、秘書のほかの役は金庫に触れない。

## 封じた場所

- 秘書のモデル CLI の組み込みの道具（ファイルを読む・書く・探す、シェル）は、書き方（`~` や前後の空白を含む）によらず、ゲートウェイの置き場所（金庫とゲートウェイのデータベース）と、Famulen が起動するときに読む `.env` に届くなら、権限にかかわらず断られ、断ったことはゲートウェイの控えに残る。
- 秘書のシェルのコマンドは、モデル CLI の砂場（サンドボックス）の中で動く。砂場は、封じた場所を、どんな道筋（相対の道、`cd`、リンク）からも読ませず書かせない。砂場を開けない環境では、シェルのコマンドは砂場の外でも動かず、失敗として秘書に返る。Docker Compose で動かすときは、同梱の設定が本体のコンテナに砂場を開けるだけの許しを与える。

## サービス定義の変更

- 秘書は、足りない道具や直したい道具に気づいたら、サービス定義の変更を出せる。今の定義の全文を読み、直した全文を、変えるわけとともに出す。何が断られ、何が確認から始まるかは[ゲートウェイの仕様](../../crates/gateway/SPEC.md#サービス定義の変更)のとおり。
- 出した変更は、ほかの確認と同じく、コンソールの会話とメインの Slack の DM で主人に尋ねる。コンソールでは、今の定義との違いが行ごとに出て、主人はそれを読んでから許すか断る。
- 許すと、その定義から足したつなぎ先の道具が変わり、秘書は次のターンから新しい道具を使える。秘書には、入ったか、入らなかったわけが届く。
- 主人は、設定のサービスの頁で、入った変更とその違いを読み、定義ごとに一つ前に戻せる。

## 控え

- 主人は、コンソールの金庫の頁の「控えを見る」から、ゲートウェイの控えを読む。呼ぶ者・つなぎ先・裁き（許可・確認・断り）で絞れる。
- 控えごとに、時刻・呼ぶ者・つなぎ先と道具・裁きとわけ・使った秘密の名前・結果・かかった時間が出る。本文と秘密の中身は出ない。

## テストで押さえること

- 秘書のモデル CLI には、Famulen の道具の口だけが渡り、外の MCP サーバーは渡らない
- 秘書が呼んだつなぎ先の道具は、ゲートウェイを通ってつなぎ先に届き、控えに秘書として残る
- 手代は、渡された道具のほかは呼べない
- 見張りのモデルには、ゲートウェイの道具が渡らない
- ワークグループに入らないつなぎ先の道具は、許可の権限でも確認になる
- ゲートウェイが出した札は、どの道から出たものでも主人に尋ねられ、Famulen を動かし直したあとも尋ねられる
- 確認の答えはゲートウェイの札への答えになり、承認した呼び出しだけが 1 回通る
- 秘書が入れようとした秘密を尋ねているあいだ、データディレクトリのどこにも中身は平文で残らない
- 金庫の頁から開くゲートウェイの控えは、呼ぶ者・つなぎ先・裁きで絞れ、本文と秘密を出さない
- 保留の札は、コンソールとメインの Slack の DM に確認として届く
- Slack の出来事はチャネルに、Google のメールの知らせは見張りに、カレンダーの知らせはカレンダーに、そのまま渡る
- あとから足したつなぎ先も、Famulen を動かし直さずに受け始める
- 主人が選んでいない受け口は、サービス定義が勧める宛先に渡り、勧めのない受け口は見張りに渡る
- 受け口の渡す先を選び直すと、次に届いたものからその先へ渡り、控えに残る
- どこにも渡さないと選んだ受け口は閉じたままで、届いたものは受け付けない
- 秘密の欄の値は、つなぎ先の頁にも API の答えにも出ない
- ゲートウェイの受け口に外から届かないときも、Slack と Gmail は受けられ、カレンダーは決まった間隔で読み直される
- 知らせを受けたのに読めなかった Gmail のメールも、あとで前に読んだところから読み直され、見張りに届く
- 秘書の Slack への返事と確認の投稿は、ゲートウェイを通って届く
- 主人と秘書は金庫に秘密を足して消せ、どの答えにも中身は出ず、秘書が消すときは確認になる
- 登録したモデルの鍵は金庫にだけ入り、呼ぶときにゲートウェイが付け、モデルを外すと消える
- 権限を決めていない組み込みの道具は、読むだけなら尋ねずに使われ、シェルは見極めが通しても確認になる
- Famulen 自身の道具のうち API の定義で確かめると決めたものは、自動でも確認になる
- 秘書の組み込みの道具は、許可の権限でも、ゲートウェイの置き場所と `.env` には届かず、手帳には届く
- 秘書のシェルのコマンドは、ゲートウェイの置き場所と `.env` を名指さずにたどっても、読めず書けない
- 見張りと手代が金庫を読もうとしても、変えようとしても断られる
- 秘書が金庫に渡した秘密は、秘書の動きの記録に残らない
- 貼った設定から、つなぎ方・名前・環境変数・鍵のヘッダーが読み取られ、読み手に任せた値は空になる
- 足すときに入れた鍵と環境変数の値は、金庫にだけ入る
- 金庫の頁で足した秘密は一覧に中身なしで出て、入れた欄は空に戻り、消すときは頁の中で確かめてから消える
- 秘書が出したサービス定義の変更は、コンソールで今の定義との違いが出て、許すと道具が増え、戻すと元の道具に戻る
