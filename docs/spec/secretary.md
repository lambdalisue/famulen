# 秘書

主人と話し、判断し、手帳を書く役。いくつもの[会話](#会話)を、一度に一つずつ進める。

## ターン

- 秘書のターンは入力で始まる。入力は、チャネルからの頼み、[定期の仕事と起床予約](schedules.md)、確認の答え、[見張り](lookout.md)の知らせ、[手代](worker.md)に委ねた仕事の終わり、終わったかもしれない[作業記憶](memory.md#夢)、つなぎ先から秘書に直に届く知らせ（[受け口と宛先](gateway.md#受け口と宛先)）のどれか。
- 入力は残されてから一つずつ秘書に渡る。秘書が仕事をしている間に届いた入力は、その仕事が終わってから順に渡る。Famulen が動き直しても、残った入力から続ける。
- 入力には、主人の現地時刻、[ワークグループ](workgroups.md)、そこで使ってよいつなぎ先とアカウントが添えられる。
- Famulen が途中で止まったとき、取り組んでいた入力は、途中で切れたことを添えてもう一度秘書に渡り、秘書は済んでいた操作を確かめてから続ける。ただし、外への呼び出しが終わらないまま止まったときは、二重にならないよう渡し直さず、主人に続けるかやめるかを[会話のカード](console.md#会話)で尋ねる。

## 会話

- 秘書の会話はスレッドごとに分かれる。秘書は、その会話で話したことと記憶は知っているが、ほかの会話の中身は知らない。
- 入力がどの会話に入るかは、次のとおり Famulen が決める。
  - 返信と、Slack のスレッドの中の発言は、そのスレッドの会話に入る。秘書がほかの会話で言った発言への返信は、その会話に入る。
  - 主人がスレッドの外で言ったことは、同じワークグループ（Slack では同じチャンネル）で主人がスレッドの外で話していた会話の、最後の発言から 10 分以内か、その仕事が終わっていないあいだなら、その会話の続きになる。過ぎていれば新しい会話になる。送るときに、続ける会話や、新しい会話にすることを指すこともできる。
  - 委ねた仕事の終わり・確認の答え・起床予約は、それを頼んだ会話に戻る。コンソールで頼んだものなら、秘書の発言は頼んだ発言のスレッドに入る。
  - 見張り・つなぎ先の知らせ・定期の仕事と、主人が許した問いへの答えは、1 件ごとに別の会話になる。
- 主人が指さないのに始まった新しい会話と、見張りの会話には、直近の一日にほかで言われたことが、量を限って添えられる。スレッドの外で続けて話したときは、そのあいだにほかで言われたことが添えられる。添えるのは主人と秘書の発言だけで、ほかのワークグループの発言、主人以外の人の発言と、それへの返事は添えない。Slack のチャンネルで答えるときと、主人が許した問いに答えるときは、ほかで言われたことは何も添えない。
- 会話を始めるときと続けるときには、心得、長期記憶の索引、進めている仕事の一覧が秘書に渡る（[記憶](memory.md)）。
- 秘書は、どの会話の発言も、Slack のものも含めて読める。
- 会話が長くなると、モデルの窓がいっぱいになるよりずっと前に、ひとりでに要約される。発言は消えない。
- Famulen が動き直しても、どの会話も続く。モデル CLI の側で会話が失われていれば、そこで言われたことを添えて始め直す。

## 外へ出すもの

- 秘書が外へ出すものは、コンソールへの発言や Slack への投稿を含め、すべて道具の呼び出しになる。モデルが最後に書いたテキストは、どこにも送られない。
- 知らせることがないターンは、何も外に出さない。
- 秘書は、コンソールへの発言と Slack への投稿を、入力の来たチャネルに合わせて選ぶ。コンソールの[返信](console.md#会話)に答えた発言は、秘書が指さなくても、その返信のスレッドに入る。秘書は、ほかの入力に取り組むときも、スレッドを読み、スレッドを指して発言できる。
- 道具は、Famulen の API の操作（主人だけに許すものを除く）と、[ゲートウェイ](gateway.md)のつなぎ先の道具。どちらも使うたびに[道具の権限](tool-permissions.md)で裁かれる。
- 秘書は、鍵の要らない[つなぎ先を足せる](gateway.md#つなぎ先の足し方)。鍵や秘密の要るものは、主人に頼む。

## 手帳を参照できる入力

- 主人以外の人の言葉を含む入力（主人以外の人の Slack の発言と、他の人の発言が前の流れとして添えられた主人の発言）では、秘書は手帳を参照できない。記憶も記録も渡らず、読む道具も書く道具も使えない。できるのは、その発言のあった場所への返事と、主人への問い合わせだけ。主人との会話も見えず、そこでの会話は主人とのどの会話にも残らない。
- 主人が他の人の言葉を自分で引いて頼んだものは、主人の入力で、制限されない。
- 主人以外の人が手帳にあることを尋ねたとき、秘書はその場で答えず、主人に[確認](tool-permissions.md#確認)で尋ねる。だれが、どこで、何を聞いているかと元の発言が載る。相手には、確かめてから答えるとだけ返す。主人の答えは次のどれか。
  - 教えてよい：秘書がその問いにだけ、一度だけ答える。そのターンでできるのは、Famulen の道具で手帳と予定を読むことと、元のスレッドに答えることだけ。
  - 教えない：秘書が断る。手帳は使わない。
  - 自分で答える：秘書は何も答えない。「ここでは答えない」も同じ。
  - 自分の言葉で答える：その言葉を秘書が相手に伝える。手帳は使わない。
- 定期の仕事・起床予約・委ねた仕事の終わり・つなぎ先からの知らせでは、手帳を使える。[見張り](lookout.md#秘書に渡ったあと)の入力では、手帳を使えるが、外へ出すものは確認になる。
- 主人以外の人への返事が確認になれば、主人が承認した言葉がそのまま、手帳を使わずに伝わる。却下すれば何も答えない。主人が問いに答えたあとの返事は、改めて尋ねない。
- 手帳を参照できない形で答えたことは、ログに残る。

## 広い場で言うもの

- 秘書は、読んだ機密を、それを読める人より広い場に書かない。機密を読んだあとで広い場に書くときは、送る前に主人に[確認](tool-permissions.md#確認)が出て、承認すれば送り、却下すれば送らない。
- 機密に数えるのは、公開と確かめられないものすべて。つなぎ先や道具が足されても、何もしなければその答えは機密になる。手帳では、人に関わる記録と記憶、物・契約と主人が足した種類の記録、秘書との会話の履歴、金庫に関わるものを数える。
- 公開として数えないのは、Famulen が確かめられるものだけ。アカウントなしで誰でも読める公開リポジトリの内容、鍵の要らない公開のフィード、ログインせずに誰でも見られる Bluesky の投稿、ウェブの検索と、公開のインターネットにある鍵の要らない頁。手帳の仕事のタスク・Famulen が持つ予定・人に関わらない記憶も数えない。社内に公開でも社外に公開でないもの（internal のリポジトリ、社内の wiki など）、認証付きで読むもの、手帳の外のファイル、シェルの出力、手代の仕事の結果、公開か確かめられなかったものは機密。
- Slack の公開チャンネルの発言は、同じワークスペースの、外部と共有していない場では数えない。外部と共有する場と、ほかのつなぎ先へ出すときは機密に数える。
- 主人との DM とコンソールでは尋ねない。公開でないチャンネルで読んだものを、そのチャンネルに書くときも尋ねない。公開かどうかを Slack から確かめられない場は、公開として扱う。
- 前のターンで読んだものは会話に残るので、読んだものの印は会話にも付き、その会話の後のターンでも効く。会話に添えられたほかの会話の発言は、その会話の印も連れてくる。
- 印のないターンでも、主人との DM のほかへ書くときは、送る文を[見極め](roles.md)が読み、人の評価・公開でないやりとり・手帳の機密を含みそうなら確認になる。見極めが使えないときも確認になる。
- 確認には、送る文、送り先（チャンネルの名前、公開かどうか、人数、外部との共有）、尋ねたわけ（読んだつなぎ先の名前など）が出る。主人との DM とコンソールにだけ出て、「今後は常に許可」はない。`send_slack` を常に許可にしていても尋ねる。
- 承認したあと、そのターンと承認の続きのターンでは、同じチャンネルへ、そのとき読んでいたものの範囲で書くことは尋ねない。新しい機密を読めば、また尋ねる。
- 主人が、そのターンの自分の言葉で、そこで言ってよいとはっきり言った発言は、尋ねない。許しの言葉は見極めが探し、その言葉が主人の発言にそのままあるときだけ効く。
- 読んだものの印は、そのターンで予約した起床、委ねた仕事、作ったり直したりした定期の仕事、書いた記録と記憶にも付き、その続きのターンと、それを読み直すターンで効く。主人が Slack で添えたファイルの中身は、添えた場へ返すときは尋ねない。
- つなぎ先の道具で Slack に書くことも同じに扱う。ほかの、外の人に届くつなぎ先の道具（メールを送る、公開に投稿するなど）は、機密を読んだターンでは常に許可にしていても確認になる。同じつなぎ先で読んだものを、そのつなぎ先で返すことは除く。ただし GitHub では、同じリポジトリへ返すときだけ除く。
- 出した確認とその答え、確認なしで通した主人の言葉は、ログに残る。

## 重い仕事を委託する

- 秘書は、主人との会話を止める重い仕事（長い調査や長い文書、コードを書くことと直すことのすべて）を自分ではせず、[手代](worker.md)に委ねる。秘書がするのは、依頼を書くこと、結果を確かめること、主人に報告すること。軽い調べものと、手帳の記録と記憶は自分でする。
- 委ねる仕事はタスクになり、優先度の順に動く。秘書は、サブエージェントも Adroit のセッションも自分では始められない。
- 秘書が自分の組み込みの道具で手帳の外のファイルを書くときは、権限が自動なら、見極めに任せず必ず主人に確認する。書ける場所に足した場所でも同じ。

## スキルと書ける場所

- 秘書は、主人の Claude Code のスキル（主人のスキルのディレクトリにあるものと、有効にしたプラグインのスキル）をすべて使える。主人がスキルを足したり直したりすると、秘書が次に起動したときに使えるようになる。主人のスキルそのものは書き換えない。
- 主人の Claude Code の設定のうち、道具を許す決まりは秘書に効かない。スキルを別のエージェントで動かす決まりも効かない。スキルが尋ねずに道具を使えるよう書いていても、フックを持っていても、秘書ではその記述は効かず、道具は呼ぶたびに裁かれる。スキルを読み込むこと自体は尋ねない。
- 秘書のシェルのコマンドが書けるのは、作業の場所と手帳のほかは、主人が秘書の頁の「秘書が書ける場所」に足した場所だけ。最初は一つもない。足せるのは主人だけで、秘書は外すことしかできない。読むほうは、これに関係なく変わらない。
- 主人は書ける場所を、パスを書いて足すほか、Famulen が動いているマシンのフォルダをたどっていくつもまとめて選ぶか、フォルダをコンソールに落として足せる。ブラウザがフォルダの名前しか渡さないときは、ホームの下から同じ名前のフォルダを探し、いくつもあれば主人が選ぶ。どの方法でも、足す前に足す場所が見える。
- 書ける場所の下にある場所は、もう書けるので足せない。ある場所を足すと、その下にすでにある場所はその場所にまとまる。
- ゲートウェイの置き場所と `.env` は、書ける場所に足しても、それを含む場所を足しても、読めも書けもしない（[封じた場所](gateway.md#封じた場所)）。
- 書ける場所を変えると、秘書が今の仕事を終えてから効く。

## 夜と使い始め

- 秘書は主人が決めた頻度で、会話とは別のセッションで[夢](memory.md#夢)を見て記憶を整理し、記録を軽く整える。
- 主人が求めたとき、秘書は[過去のやりとりから手帳を作る](notebook.md#過去のやりとりから作る)。

## テストで押さえること

- チャネル・定期の仕事・起床予約・確認の答え・見張り・委ねた仕事の終わりは、どれも入力として残されてから秘書に渡る
- 動き直したあと、残った入力から続き、どの会話も再開する
- 2 つのスレッドを行き来しても、それぞれの会話に入り、互いの発言は渡らない
- スレッドの外の発言は、最後の発言から間がなければ同じ会話に、あれば新しい会話に入り、指した会話があればそこに入る
- 委ねた仕事の終わり・確認の答え・起床予約は、頼んだ会話に戻り、頼んだ発言のスレッドで答えられる
- 見張り・つなぎ先の知らせ・定期の仕事は、1 件ごとに別の会話になる
- 新しい会話に添えられるものは量に上限があり、ほかのワークグループの発言、主人以外の人の発言と、それへの返事を含まない
- 動いているターンの会話でないプロセスからの呼び出しは断られる
- 会話を分ける前から続いている仕事は、前の会話に戻る
- モデルの最後のテキストは、どこにも送られない
- 返信への答えは同じスレッドに入り、返信でない主人の発言への答えはスレッドに入らない
- 道具を呼ばずに終わったターンは、何も外に出さない
- 入力には、現地時刻とワークグループと使ってよいつなぎ先が添えられる
- 秘書は道具でサービス定義の変更を出せ、主人の答えを待つ
- 秘書の道具に、鍵の要らないつなぎ先を足すものがあり、主人の画面のつなぎ先を足す操作はない
- 主人のスキルとプラグインのスキルは、道具を許す記述とフックを除いて作業場所に写され、主人のスキルそのものは書き換えない
- 主人の設定からは有効なプラグインだけを読み、ほかの決まりは秘書に渡らない
- スキルを読み込むことは尋ねずに許される
- 書ける場所は最初は空で、主人が足した場所だけがシェルの砂場で書けるようになる
- 封じた場所は、書ける場所に足しても読み書きとも禁止のまま
- 書ける場所を足すことは秘書の道具にない
- 書ける場所の下は足せず、上を足すと下にあった場所はなくなる
- 主人以外の人の発言と、他の人の言葉が添えられた主人の発言では、返事と主人への問い合わせのほかの道具がわけとともに断られ、記憶も記録も主人との会話も渡らない
- 主人の発言では、手帳の道具をこれまでどおり使える
- 主人以外の人への返事は、その発言のあった場所とスレッドにしか届かない
- 主人以外の人が尋ねたことは、入力ごとに一度だけ主人に確認され、元の発言が載る
- 主人が教えてよいと答えたときだけ、読むことと元のスレッドへの返事だけができるターンになる
- 秘書の指示に、手帳を主人以外の人に見せないことが入っている
- 人の記録を読んだターンで公開のチャンネルに書くと確認になり、読んでいないターンの普通の返事は確認にならない
- 主人との DM とコンソールへは、何を読んでいても確認にならない
- 公開でないチャンネルの内容は、ほかの場へ出すと確認になり、同じチャンネルへ返すと確認にならない
- 公開かどうか分からない場は、公開として扱う
- 承認すると送られ、同じ場への同じ範囲の続きは確認にならず、却下すると言い換えても確認になる
- 見極めが引いた許しの言葉が主人の発言にないときは、確認になる
- 見極めが使えないときは、確認になる
- Famulen の道具で、機密でないと決めていないものの答えは、機密に数える
- 知らないつなぎ先の答えは、読む道具でも書く道具でも機密に数え、公開の場へ書くと尋ねたわけにつなぎ先の名前が出る
- 公開と確かめられたリポジトリの内容は機密に数えず、非公開のものと確かめられないもの、アカウントに属するものは機密に数える
- 鍵の要らない公開のフィードと、ログインせずに見られる Bluesky の投稿は機密に数えず、鍵や認証の付いたフィード、タイムラインと通知は機密に数える
- ウェブの頁は、公開のインターネットにあって鍵も認証もないときだけ機密に数えない
- 手帳の外のファイル、シェルの出力、知らない組み込みの道具の答えは機密に数え、スキルは数えない
- Slack の公開チャンネルの発言は、同じワークスペースの外部と共有しない場へは確認にならず、外部と共有する場とほかのつなぎ先へは確認になる
- 会話で読んだ機密は、その会話の後のターンでも確認になり、ほかの会話では確認にならない
- 会話に渡したもの、添えたほかの会話の発言、定期の仕事、書いた記録と記憶に、読んだものの印が引き継がれ、道具でもファイルとしても読み直すと効く
- GitHub の非公開のリポジトリで読んだものは、同じリポジトリへは尋ねず、ほかのリポジトリへは尋ねる
- 公開のリポジトリでも、送っていないレビューと公開していないリリースは機密に数える
- 鍵をリンクに持つ共有の頁と、鍵らしいものが道筋にある頁は、公開に数えない
- 添えられたファイルの中身は、添えた場へは確認にならず、ほかの場へは確認になる
- 送る・押し込む・招く道具も、ほかの人に届く道具に数える
- 手代の仕事の結果は、何を渡したかによらず機密に数える
- 秘書の指示に、広い場で人の評価や公開でないやりとりを書かないことが入っている
- 秘書の指示に、重い仕事をタスクとして委ねることが入っている
- 秘書には、エージェントを始める組み込みの道具も Adroit のセッションを始める道具も渡らず、呼んでも断られる
- 秘書が手帳の外のファイルを書く呼び出しは、見極めが通しても確認になり
