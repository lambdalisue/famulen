# 秘書

主人と話し、判断し、手帳を書く役。常駐する 1 つのセッションとして動く。

## ターン

- 秘書のターンは入力で始まる。入力は、チャネルからの頼み、[定期の仕事と起床予約](schedules.md)、確認の答え、[見張り](lookout.md)の知らせ、[手代](worker.md)に委ねた仕事の終わり、終わったかもしれない[作業記憶](memory.md#夢)、つなぎ先から秘書に直に届く知らせ（[受け口と宛先](gateway.md#受け口と宛先)）のどれか。
- 入力は残されてから一つずつ秘書に渡る。秘書が仕事をしている間に届いた入力は、その仕事が終わってから順に渡る。Famulen が動き直しても、残った入力から続ける。
- セッションは 1 つで、Famulen が動き直しても同じ会話を続ける。
- 入力には、主人の現地時刻、[ワークグループ](workgroups.md)、そこで使ってよいつなぎ先とアカウントが添えられる。
- 会話を始めるたびに、心得、長期記憶の索引、進めている仕事の一覧が秘書に渡る（[記憶](memory.md)）。
- Famulen が途中で止まったとき、取り組んでいた入力は、途中で切れたことを添えてもう一度秘書に渡り、秘書は済んでいた操作を確かめてから続ける。ただし、外への呼び出しが終わらないまま止まったときは、二重にならないよう渡し直さず、主人に続けるかやめるかを[会話のカード](console.md#会話)で尋ねる。

## 外へ出すもの

- 秘書が外へ出すものは、コンソールへの発言や Slack への投稿を含め、すべて道具の呼び出しになる。モデルが最後に書いたテキストは、どこにも送られない。
- 知らせることがないターンは、何も外に出さない。
- 秘書は、コンソールへの発言と Slack への投稿を、入力の来たチャネルに合わせて選ぶ。
- 道具は、Famulen の API の操作（主人だけに許すものを除く）と、[ゲートウェイ](gateway.md)のつなぎ先の道具。どちらも使うたびに[道具の権限](tool-permissions.md)で裁かれる。
- 秘書は、鍵の要らない[つなぎ先を足せる](gateway.md#つなぎ先の足し方)。鍵や秘密の要るものは、主人に頼む。

## 手帳を参照できる入力

- 主人以外の人の言葉を含む入力（主人以外の人の Slack の発言と、他の人の発言が前の流れとして添えられた主人の発言）では、秘書は手帳を参照できない。記憶も記録も渡らず、読む道具も書く道具も使えない。できるのは、その発言のあった場所への返事と、主人への問い合わせだけ。主人との会話も見えず、そこでの会話は主人との会話に残らない。
- 主人が他の人の言葉を自分で引いて頼んだものは、主人の入力で、制限されない。
- 主人以外の人が手帳にあることを尋ねたとき、秘書はその場で答えず、主人に[確認](tool-permissions.md#確認)で尋ねる。だれが、どこで、何を聞いているかと元の発言が載る。相手には、確かめてから答えるとだけ返す。主人の答えは次のどれか。
  - 教えてよい：秘書がその問いにだけ、一度だけ答える。そのターンでできるのは、Famulen の道具で手帳と予定を読むことと、元のスレッドに答えることだけ。
  - 教えない：秘書が断る。手帳は使わない。
  - 自分で答える：秘書は何も答えない。「ここでは答えない」も同じ。
  - 自分の言葉で答える：その言葉を秘書が相手に伝える。手帳は使わない。
- 定期の仕事・起床予約・委ねた仕事の終わり・つなぎ先からの知らせでは、手帳を使える。[見張り](lookout.md#秘書に渡ったあと)の入力では、手帳を使えるが、外へ出すものは確認になる。
- 主人以外の人への返事が確認になれば、主人が承認した言葉がそのまま、手帳を使わずに伝わる。却下すれば何も答えない。主人が問いに答えたあとの返事は、改めて尋ねない。
- 手帳を参照できない形で答えたことは、ログに残る。

## 重い仕事を委託する

- 秘書は、主人との会話を止める重い仕事（長い調査や長い文書、コードを書くことと直すことのすべて）を自分ではせず、[手代](worker.md)に委ねる。秘書がするのは、依頼を書くこと、結果を確かめること、主人に報告すること。軽い調べものと、手帳の記録と記憶は自分でする。
- 委ねる仕事はタスクになり、優先度の順に動く。秘書は、サブエージェントも Adroit のセッションも自分では始められない。
- 秘書が自分の組み込みの道具で手帳の外のファイルを書くときは、権限が自動なら、見極めに任せず必ず主人に確認する。書ける場所に足した場所でも同じ。

## スキルと書ける場所

- 秘書は、主人の Claude Code のスキル（主人のスキルのディレクトリにあるものと、有効にしたプラグインのスキル）をすべて使える。主人がスキルを足したり直したりすると、秘書が次に起動したときに使えるようになる。主人のスキルそのものは書き換えない。
- 主人の Claude Code の設定のうち、道具を許す決まりは秘書に効かない。スキルを別のエージェントで動かす決まりも効かない。スキルが尋ねずに道具を使えるよう書いていても、フックを持っていても、秘書ではその記述は効かず、道具は呼ぶたびに裁かれる。スキルを読み込むこと自体は尋ねない。
- 秘書のシェルのコマンドが書けるのは、作業の場所と手帳のほかは、主人が秘書の頁の「秘書が書ける場所」に足した場所だけ。最初は一つもない。足せるのは主人だけで、秘書は外すことしかできない。読むほうは、これに関係なく変わらない。
- 主人は書ける場所を、パスを書いて足すほか、Famulen が動いているマシンのフォルダをたどっていくつもまとめて選ぶか、フォルダをコンソールに落として足せる。ブラウザがフォルダの名前しか渡さないときは、ホームの下から同じ名前のフォルダを探し、いくつもあれば主人が選ぶ。どの方法でも、足す前に足す場所が見える。
- 書ける場所の下にある場所は、もう書けるので足せない。ある場所を足すと、その下にすでにある場所はその場所にまとまる。
- ゲートウェイの置き場所と `.env` は、書ける場所に足しても、それを含む場所を足しても、読めも書けもしない（[封じた場所](gateway.md#封じた場所)）。
- 書ける場所を変えると、秘書が今の仕事を終えてから効く。

## 夜と使い始め

- 秘書は主人が決めた頻度で、会話とは別のセッションで[夢](memory.md#夢)を見て記憶を整理し、記録を軽く整える。
- 主人が求めたとき、秘書は[過去のやりとりから手帳を作る](notebook.md#過去のやりとりから作る)。

## テストで押さえること

- チャネル・定期の仕事・起床予約・確認の答え・見張り・委ねた仕事の終わりは、どれも入力として残されてから秘書に渡る
- 動き直したあと、残った入力から続き、同じ会話を再開する
- モデルの最後のテキストは、どこにも送られない
- 道具を呼ばずに終わったターンは、何も外に出さない
- 入力には、現地時刻とワークグループと使ってよいつなぎ先が添えられる
- 秘書は道具でサービス定義の変更を出せ、主人の答えを待つ
- 秘書の道具に、鍵の要らないつなぎ先を足すものがあり、主人の画面のつなぎ先を足す操作はない
- 主人のスキルとプラグインのスキルは、道具を許す記述とフックを除いて作業場所に写され、主人のスキルそのものは書き換えない
- 主人の設定からは有効なプラグインだけを読み、ほかの決まりは秘書に渡らない
- スキルを読み込むことは尋ねずに許される
- 書ける場所は最初は空で、主人が足した場所だけがシェルの砂場で書けるようになる
- 封じた場所は、書ける場所に足しても読み書きとも禁止のまま
- 書ける場所を足すことは秘書の道具にない
- 書ける場所の下は足せず、上を足すと下にあった場所はなくなる
- 主人以外の人の発言と、他の人の言葉が添えられた主人の発言では、返事と主人への問い合わせのほかの道具がわけとともに断られ、記憶も記録も主人との会話も渡らない
- 主人の発言では、手帳の道具をこれまでどおり使える
- 主人以外の人への返事は、その発言のあった場所とスレッドにしか届かない
- 主人以外の人が尋ねたことは、入力ごとに一度だけ主人に確認され、元の発言が載る
- 主人が教えてよいと答えたときだけ、読むことと元のスレッドへの返事だけができるターンになる
- 秘書の指示に、手帳を主人以外の人に見せないことが入っている
- 秘書の指示に、重い仕事をタスクとして委ねることが入っている
- 秘書には、エージェントを始める組み込みの道具も Adroit のセッションを始める道具も渡らず、呼んでも断られる
- 秘書が手帳の外のファイルを書く呼び出しは、見極めが通しても確認になり
