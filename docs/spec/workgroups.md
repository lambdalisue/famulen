# ワークグループ

仕事・個人のように、主人が頼みごとと使うものを分ける単位。

- 「すべて」は最初からあり、消せない。それ以外のワークグループは、主人が名前とテーマの色を決めて足し、消せる。最初は「仕事」と「個人」がある。
- 主人はチャネル・つなぎ先・見張りを、それぞれどのワークグループに入れるかを決める。いくつのワークグループに入れてもよい。
- ワークグループごとに、カレンダーごとの出し方（出す・薄く出す・出さない）と、使うアカウント（メールを送る・予定を入れる・Slack に投稿する）を決める。カレンダーは、決めるまではどのワークグループでも出す。
- ワークグループの名前・色・並びと、カレンダーごとの出し方は手帳に書かれる。チャネル・つなぎ先・見張り・使うアカウントとの結びつきは、設定として Famulen のデータベースが持つ。
- 記録と記憶にはワークグループの印が付く。秘書が、どこから来たか（仕事の Slack から、など）で付け、主人も直せる。印はいくつ付いていてもよい。
- 主人がワークグループを選ぶと、コンソールの会話と右の画面はそこに入るものだけを使い、見せる。
- チャネルから来た頼みは、そのチャネルが入っているワークグループのこととして受ける。入っている先が一つでなければ「すべて」として受ける。
- ワークグループを消しても、記録と記憶は消えない。どのワークグループにも入らないものは「すべて」でだけ見える。

## 秘書の振る舞い

- 秘書には、入力ごとにワークグループと、そこで使ってよいつなぎ先と、使うアカウントが伝わる。
- 「すべて」のほかのワークグループで、そこに入らないつなぎ先の道具を呼ぶと、許可の権限でも確認になる。
- 出さないカレンダーの予定も、空いていない時間として扱う。

## テストで押さえること

- 「すべて」は消せず、ほかのワークグループは足して消せる
- ワークグループを消しても、その印が付いた記録は残る
- 手帳で足したワークグループは、コンソールにも出る
- チャネルが一つのワークグループにだけ入っていれば、そこからの頼みはそのワークグループのことになる
- ワークグループに入らないつなぎ先の道具は、許可の権限でも確認になる
- 入力には、ワークグループと使うアカウントが添えられる
