# 記憶

秘書がやりとりから覚えたこと。[手帳](notebook.md)の `memory/` に置く。予定・タスク・相手などの記録は記憶に入らない。

## 層と書き方

心得・気づき・作業記憶・保留中の判断・長期記憶（意味記憶・手続き記憶・展望記憶）・忘却の層からなる。層の置き場所と書き方は[手帳の仕様](../../crates/notebook/SPEC.md#記憶)のとおり。Famulen では、`src` の持ち主は主人で、`workgroup` は[ワークグループ](workgroups.md)の ID、気づきを整理するのは夢。心得の行数は主人が決める（決めなければ 150 行）。

## 昼

- 秘書は気づいたことを気づきに書き、進めている仕事の途中経過を作業記憶に書く。
- 気づきは、日付に関わらず雑に書く受信箱で、夢が整理したら消える。作業記憶は、進めている仕事の途中経過で、仕事が終われば閉じる。
- 書くときに触れた記録は、code・題名・ID でリンクし、決まった形で残る。リンクした記憶は、その記録の頁に出る。
- 書く価値があるかは選ばず、雑に、どんどん書く。選ぶのは夢。
- 秘書は会話の中で心得・保留中の判断・長期記憶を書かない。主人がはっきり言った決まりや訂正も、主人の言葉（`src=said`）として気づきに書き、夢が入れる。夢を待つあいだも、会話を始めるたびに、多ければ新しいほうから秘書に渡り、秘書はそれに従う。
- 心得と、夢を待つ主人の言葉と、長期記憶の索引（ファイルの一覧）と、作業記憶の題名は、会話を始めるたびに秘書に渡る。心得は、有効な期間のものが決めた行数まで渡る。
- 会話のターンで記憶が変わると、1 つのコミットになる。

## 夢

- 主人が決めた頻度（毎晩・一日おき・週に一度の決めた曜日）で、決めた時刻を過ぎたら、秘書の会話とは別のモデルで夢を見る。決めなければ毎晩 4:00。時刻はワークグループ全体のタイムゾーンで数える。
- 夢を待つ気づきが決めた数（決めなければ 30 件）たまったら、時刻を待たずに早めに見る。数を 0 にすると、早めには見ない。[見張りが書き出した人の気づき](lookout.md#人についての気づき)は、この数に入らない。早めの夢は、次の決めた時の夢を動かさない。
- 見られなかった夢は、間をだんだん空けて何度かやり直す。やり直しても見られなければ、その日の夢はあきらめる。
- 主人はいつでも今すぐ夢を見させられる。
- 夢は気づきを、この一日の会話と今ある記憶と比べて、足す・直す・置き換える・確かめる・忘れる・保留にする・捨てるのどれかを選ぶ。片づけなかった項目は、三度までは次の夢でもう一度読み、それでも片づかなければ、捨てずに保留にする。
- 気づきは雑な走り書きでよい。夢が残すのは、主人の言ったことや確かな事実のうち長く効くものと、繰り返し出るものだけで、一度きりの出来事・途中経過・すでに記録にあるもの・じきに古くなるものは捨てる。まだ記録にない、することは捨てない。この一週間に捨てたものは次の夢も見るので、繰り返せば気づく。
- 人についてのことは、一度見ただけでも捨てずに保留にし、重なれば長期記憶に入れる。
- 夢のあと、一日に一度まで、人の気づきを秘書に渡す。秘書は、主人に関わる人でまだない人を、一度の出現でも[相手](records.md#相手)に足し、最後に出た日を新しくする。名前・所属・役目・関係は、確かな出どころで確かめられたときに直す。推し量った人となりは相手の記録に書かず、記憶に置く。
- 夢のあと、記憶に出た相手の最後に出た日を新しくし、[長く出てこない人を休みにする](records.md#相手)。
- 夢が整理を終えた気づき（記憶や記録に入れたもの、保留に移したもの、捨てたもの）は消える。捨てたものとわけは、消す前に夜の記録に書き、書けなければ消さない。まだ判断できないものは残り、次の夢を待つ。人についての気づきは、相手の記録に反映するまで残す。消したものも、手帳の Git の履歴には残る。
- 足す前に今ある記憶と比べ、重なれば足さずに、ある記憶を確かめるか直す。同じ層・同じ範囲に同じ文の記憶があれば、足す代わりにそれを確かめたことにする。
- 推し量ったことを長期記憶に入れるには、別々の根拠が 2 つ要る。手続き記憶は、主人が確かめたものか、一度うまくいったものだけを入れる。推し量ったことを覆すには根拠が 2 つ、主人の言ったことを覆すには、それより新しい根拠が 3 つか、主人自身の訂正が要る。
- 決めきれないものは保留中の判断に置く。主人には尋ねない。話の流れで自然に確かめられるときだけ聞く。
- 心得が決めた行数を超えそうなら、使われていないものから長期記憶に下ろす。一晩で半分より小さくはしないので、行数を大きく縮めると幾晩かかけて収まる。
- 記憶に紛れたもののうち、することは主人のタスクに、頼りにする事実はメモに移す。することには、分かる限り期日と始める日を付け、もとの記憶を書き添える。同じワークグループに同じ題名のまだ済んでいないタスクがあれば、足さずにその経過に書く。移せないものは記憶に残る。
- 記憶の変更は 1 つのコミットにまとまる。ファイル（長期記憶は分類ごと）の項目を半分より少なくする変更と、主人の言ったことを忘却に移さず消す変更は当てない。
- 記憶が整ったら、主人が止めていない限り、[記録も軽く整える](records.md#夢が整える)。記録を整えられなくても、記憶の変更は残る。
- 夢は、終わったかもしれない作業記憶（触れているタスクがすべて終わったもの、しばらく書かれていないもの）を、閉じるか確かめるよう一日に一度まで秘書に尋ね、尋ねたことを夜の記録に残す。作業記憶そのものは閉じも書き換えもしない。
- 夢が 1 日の上限に達しているあいだは、夢を見ない。記憶を整えて上限に達したら、その夜は記録を整えない。

## 主人が見るもの

- コンソールの記憶で、層ごとに中身を見られる。心得は大きさの上限とともに出る。気づきには、選んだワークグループの、夢を待つものだけが日ごとに出る。気づきの件数は、すべてのワークグループの、夢を待つものの数。
- 記憶は[記録](records.md)の備考と同じに描かれ、手帳の中へのリンクは、その記録か記憶を開く。属性は記憶の文と分けて出る。書き換えるときは、ファイルの文をそのまま書く。
- 夢の頁では、夜ごとの変更の数と、記憶と記録の変更とその理由、捨てた気づきとその理由を見られ、前後の夜に移れる。
- 設定の夢の頁で、夢のモデルとともに、頻度・時刻・早めに見る数・心得の行数・相手を休みにするまでの日数と、記録も整えるかを決める（決めなければ整える）。頁は次に夢を見る時を示し、今すぐ夢を見る操作も置く。
- 主人は記憶を直接書き換えられる。その変更は主人のものとして Git に残る。

## テストで押さえること

- 会話のターンで記憶が変わったら、1 つのコミットになる
- 主人の書き換えは主人のコミットになる
- 記録をリンクした記憶は、その記録を開くと出て、記憶から記録へも移れる
- 秘書が覚える道具は行き先を選べず、夢を待つ主人の言葉はセッションに渡る
- 心得と長期記憶の索引がセッションに渡り、長い心得は切って渡される
- 夢の頻度・時刻・早めに見る数で、夢を見るかが決まる
- 見られなかった夢は、やり直しが済むまでその日の夢として数えず、決めた回数でやめる
- することは日付の確かなタスクになり、種類や日付の誤ったものは記憶に残る
- 夢には主人が決めた心得の行数が伝わる
- 夢の設定は範囲の外の値を断り、何も変えない
- 夢の変更でファイルか長期記憶の分類が半分より小さくなるとき、変更は当てられない
- 夢の変更で主人の言った記憶が消えるとき、変更は当てられない
- 触れているタスクがすべて終わった作業記憶と、しばらく書かれていない作業記憶は、一日に一度まで秘書に尋ねられ、残ったままになる
- 人の気づきは、一日に一度まで、一件につき一度だけ秘書に渡る
- 夢が整理を終えた気づきだけが消え、待つ気づきと、片づかず保留に移したものの中身は残る
- 夜の記録に書けなかった夢は、気づきを消さない
- 捨てた気づきとその理由が夜の記録に残り、しばらくは次の夢に見せられる
- 同じ層・同じ範囲に同じ文を足す変更は、もとの記憶を確かめる変更になる
- 夢の結果（操作ごとの数と変更）は、夜ごとに残り、前後に辿れる
- 記憶ディレクトリの中への書き込みは確認なしで通り、外への書き込みは権限に従う
- 記憶はどの層でも Markdown として描かれ、属性は文と分かれ、中のスクリプトは動かない
