# 記憶

秘書がやりとりから覚えたこと。[手帳](notebook.md)の `memory/` に置く。予定・タスク・相手などの記録は記憶に入らない。

## 層と書き方

心得・エピソード記憶・作業記憶・保留中の判断・長期記憶（意味記憶・手続き記憶・展望記憶）・忘却の層からなる。層の置き場所と書き方は[手帳の仕様](../../crates/notebook/SPEC.md#記憶)のとおり。Famulen では、`src` の持ち主は主人で、`workgroup` は[ワークグループ](workgroups.md)の ID、エピソード記憶を整理するのは夢。心得の行数は主人が決める（決めなければ 150 行）。

## 昼

- 秘書は気づいたことをエピソード記憶に書き、進めている仕事の途中経過を作業記憶に書く。
- 書くときに触れた記録は、code・題名・ID でリンクし、決まった形で残る。リンクした記憶は、その記録の頁に出る。
- 主人がはっきり言った決まりや訂正だけは、すぐに心得か長期記憶に入る（`src=said`）。
- 心得と、長期記憶の索引（ファイルの一覧）と、作業記憶の題名は、会話を始めるたびに秘書に渡る。心得は、有効な期間のものが決めた行数まで渡る。
- 会話のターンで記憶が変わると、1 つのコミットになる。

## 夢

- 主人が決めた頻度（毎晩・一日おき・週に一度の決めた曜日）で、決めた時刻を過ぎたら、秘書の会話とは別のモデルで夢を見る。決めなければ毎晩 4:00。時刻はワークグループ全体のタイムゾーンで数える。
- エピソード記憶に夢を待つ項目が決めた数（決めなければ 30 件）たまったら、時刻を待たずに早めに見る。数を 0 にすると、早めには見ない。早めの夢は、次の決めた時の夢を動かさない。
- 主人はいつでも今すぐ夢を見させられる。
- 夢はエピソード記憶の項目を、この一日の会話と今ある記憶と比べて、足す・直す・置き換える・確かめる・忘れる・保留にするのどれかを選ぶ。片づけなかった項目は、三度までは次の夢でもう一度読む。
- 推し量ったことを長期記憶に入れるには、別々の根拠が 2 つ要る。手続き記憶は、主人が確かめたものか、一度うまくいったものだけを入れる。推し量ったことを覆すには根拠が 2 つ、主人の言ったことを覆すには、それより新しい根拠が 3 つ要る。
- 決めきれないものは保留中の判断に置く。主人には尋ねない。話の流れで自然に確かめられるときだけ聞く。
- 心得が決めた行数を超えそうなら、使われていないものから長期記憶に下ろす。一晩で半分より小さくはしないので、行数を大きく縮めると幾晩かかけて収まる。
- 記憶に紛れた事実（契約の切れ目など）は、記録に移す。
- 夢の変更は 1 つのコミットにまとまる。ファイル（長期記憶は分類ごと）の項目を半分より少なくする変更と、主人の言ったことを忘却に移さず消す変更は当てない。
- 夢のモデルがないか、1 日の上限に達しているあいだは、夢を見ない。

## 主人が見るもの

- コンソールの記憶で、層ごとに中身を見られる。心得は大きさの上限とともに出る。
- 記憶は[記録](records.md)の備考と同じに描かれ、手帳の中へのリンクは、その記録か記憶を開く。属性は記憶の文と分けて出る。書き換えるときは、ファイルの文をそのまま書く。
- 夢の頁では、夜ごとの変更の数と、変更とその理由を見られ、前後の夜に移れる。
- 設定の夢の頁で、夢のモデルとともに、頻度・時刻・早めに見る数・心得の行数を決める。頁は次に夢を見る時を示し、今すぐ夢を見る操作も置く。
- 主人は記憶を直接書き換えられる。その変更は主人のものとして Git に残る。

## テストで押さえること

- 会話のターンで記憶が変わったら、1 つのコミットになる
- 主人の書き換えは主人のコミットになる
- 記録をリンクした記憶は、その記録を開くと出て、記憶から記録へも移れる
- 心得と長期記憶の索引がセッションに渡り、長い心得は切って渡される
- 夢の頻度・時刻・早めに見る数で、夢を見るかが決まる
- 夢には主人が決めた心得の行数が伝わる
- 夢の設定は範囲の外の値を断り、何も変えない
- 夢の変更でファイルか長期記憶の分類が半分より小さくなるとき、変更は当てられない
- 夢の変更で主人の言った記憶が消えるとき、変更は当てられない
- 夢の結果（操作ごとの数と変更）は、夜ごとに残り、前後に辿れる
- 記憶ディレクトリの中への書き込みは確認なしで通り、外への書き込みは権限に従う
- 記憶はどの層でも Markdown として描かれ、属性は文と分かれ、中のスクリプトは動かない
