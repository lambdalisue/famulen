# コンソール

主人が秘書と話し、記録と記憶を見て直す画面。本体とは別のプロセスとして動き、本体の API を使う。

## どこで開くか

- ログインはない。localhost か、Tailscale などの私的なネットワークにだけ開く。
- localhost と、設定したホスト名（[設定](config.md#環境変数と設定ファイル)）以外で開こうとすると断られる。
- 変更の操作は、コンソール自身の画面から送ったものだけが受け付けられる。[共有した手帳](notebook.md#手帳の共有)への Git の通信は、ほかのサイトの頁からは送れない形のものだけが受け付けられる。

## 形

- 右の画面の上の帯：秘書のアイコンと名前、ワークグループの切り替え、秘書の状態、ライトとダークの切り替え。ワークグループを切り替えると、その色が画面に出て、会話と右の画面の両方がそこに絞られる（[ワークグループ](workgroups.md)）。
- 左：秘書との会話。窓の上端から下端まで使う。一覧から話を選んで開く。どのチャネルから話しかけた発言も、一続きに並べて見ることもできる。
- 右：セクションのタブ。ホーム・カレンダー・タスク・メモ・相手・物・契約と、記憶・設定。広いところでは、記録は一覧と詳細が、予定はカレンダーと詳細が並ぶ（[記録](records.md#どの記録にも通じること)）。
- 記録が変わっても、一覧に続きを描いても、シートやダイアログを開いても、右の画面の見ていた位置・開いている詳細・絞り込み・入力中のフォーカスと文字は、そのまま残る。
- 会話と右の画面の境は、つかんで動かせる。幅はそのブラウザに残る。
- 一度開いた頁へ戻ると、前に読んだ中身がすぐ出て、読み直したものが届くと置き換わる。変える操作のあとは、変わったあとの中身を読んでから出す。

### ライトとダーク

- テーマは、システム・ライト・ダークから、右の画面の上の帯か設定の「表示」で選ぶ。選ばなければシステムで、端末で切り替えるとその場で替わる。
- 選んだテーマはそのブラウザに残り、開いているほかのタブにも効く。次に開く頁は、初めからそのテーマで出る。
- 主人がワークグループやカレンダーに選んだ色は、ダークでは読める明るさに補って出る。
- どちらのテーマでも、文字と入力の枠は WCAG AA のコントラストを持つ。

### スマートフォンでの形

- 狭い画面では、同じ頁が親指の届く形に組み替わる。URL は変わらない。
- よく使うもの（タブ・会話の入力・足すボタン・カレンダーの切り替え）は、画面の下に置く。ワークグループの切り替えは、下から引き上げるシートで出る。
- 押すところは、文の中のリンクとカレンダーの予定・図の棒を除き、44px 四方より狭くない。
- 会話は、画面いっぱいに開くか、秘書の最後の発言の書き出しだけに畳まれるか、どちらか。入力欄に書き始めると開く。書いているあいだ、入力欄と送るボタンはキーボードの上に収まり、長い文は入力欄の中で送って読める。開いた会話の上の帯は下へ、畳んだ会話は上へ引いて、閉じ開きできる。
- 開いた会話が出ているあいだ、裏の頁は動かず、見えもしない。閉じると、裏の頁は元の位置のまま出る。
- 開いた会話で話を開いているときは、右へ滑らせると、指に付いて話が退き、下から一覧が出る。途中で戻せば取りやめになる。ブラウザやスマートフォンの「戻る」も、頁を離れずに、話から一覧へ、一覧から会話を閉じるところへ戻る。会話に重ねて画像を開いていれば、「戻る」はその画像だけを閉じる。会話を開いたままほかの頁へ移って「戻る」で帰ったときも、頁を読み直したときも、そのときの会話がそのまま出る。広い画面では、話を開いても履歴に残らない。
- 開いた会話の中のリンクや、下のタブを押すと、会話は畳まれ、その先の画面が見える。いま見ている頁へのリンクやタブでも同じ。その先へ移ったときは、「戻る」でそのときの会話が出る。いま見ているところそのものへのリンクやタブは、閉じるボタンと同じく会話を閉じるだけで、戻る先を残さない。
- 詳細は一覧に重なって開き、戻るボタンか、左の端から滑らせる操作で一覧に戻る。
- ホーム画面に足すと、どの頁に移ってもアプリとして開き、ブラウザのメニューは出ない。ほかのサービスのログインの画面だけは、ブラウザの枠で開く。
- 画面のアイコン（タブ・ホーム画面・帯・秘書の発言）は、主人が選んだ秘書の性別に従う。選び直すと、開いているほかのタブも含めてその場で替わる。ホーム画面に足したアイコンは端末が覚えていて、足し直すまで替わらないことがある。

## 会話

### 話

- 秘書の[会話](secretary.md#会話)は、画面では「話」と呼ぶ。一覧には、題（最初の発言の書き出し）、最後の発言、未読の数、主人の答えを待っているか、動いているか、ワークグループ、どこから来たかが出る。答え待ち・未読・動いているもので絞れる。
- 話を開いているあいだに書いたことは、返信を押さなくても、その話の続きになる。一覧と「新しい話」から書けば、新しい話が始まる。前の話は引き継がない。
- 送り先は、書くときにいつも出る。「続き」と「新しい話」を切り替えられ、続きならその話の題も出る。打ちかけの文と添えたファイルは話ごとに残り、送り先を替えたときは、新しい送り先へ付いていく。
- 開いた話は、主人が読んだことになる。どの端末でも未読の数から除かれる。未読だったところの始まりには印が付く。
- 開いていない話に発言や確認が届くと、知らせが出て、そこから開ける。画面が勝手に切り替わることはない。一覧へ戻るボタンには、ほかに待っている話の数が出る。
- 確認は、尋ねた話に出る。一覧にない話の確認は、一覧に出る。
- 「一続きで見る」を選ぶと、すべての話の発言が一本に並ぶ。どれを開いていたかは、そのブラウザに残る。

### 発言

- 主人がコンソールから送った発言には、そのときのワークグループと、見ていた画面（どのタブの、どの期間・どの項目か）が添えられて秘書に渡る。「これ」で話が通じる。
- 右の項目は、「会話に添える」を押すと入力欄に札が付き、その項目も添えて渡る。開いただけでは付かない。札は外せる。
- どの発言も「返信」を押して、その発言への返信を書ける。入力欄に返信先の書き出しが出て、外せる。返信は、どの発言へのものか、返信先の文とともに秘書に渡る。
- 返信は会話の中に、返信先の書き出しを付けて出る。書き出しを押すと返信先の発言へ移る。まだ読み込んでいない古い発言なら、そこまで読み込む。
- 返信と、その返信への返信は、最初の発言から始まる一つのスレッドになる。スレッドの始まりの発言には返信の数が出て、押すとスレッドだけが開く。広い画面では会話の下に並び、狭い画面では会話に重なる。開いているあいだに書いた発言は、そのスレッドへの返信になる。
- 返信への秘書の返事は、同じスレッドに入り、会話にも出る。
- 選んだワークグループに出ない発言は、返信先の書き出しにも、返信の数にも、スレッドにも出ない。
- ファイルは、入力欄のボタンで選ぶか、入力欄に貼るか、会話の上に落として[添える](channels.md#添えたファイル)。添えたものは札になり、送る前に外せる。受け取れないものは、札にわけが出て、外すまで送れない。
- 発言に添えたファイルは、Slack から届いたものも、会話の中に出る。画像はその場で見え、押すと会話に重ねて大きく開く。閉じると、読んでいたところと打ちかけの文字に戻る。元の画像は、そこから新しいタブでも開ける。届かなかったものはわけが出る。
- 秘書の発言と確認は、来たときにその場で出る。会話は最後の発言に付いていき、主人が前を読もうと戻したときだけ止まる。止まっているあいだは、発言や確認が来ても、記録が変わっても、読んでいるところは動かない。
- 発言や確認が来ても、記録が変わっても、読み直しに失敗しても、入力欄のフォーカス・打ちかけの文字・カーソルの位置と、確認のカードで開いたところや書きかけの答えは、そのまま残る。
- 会話は新しいほうから読み込まれ、上へ戻すと、古い発言が最初の一つまで続けて読み込まれる。読み込んでも、読んでいるところは動かない。読み込めなければ、わけと、読み直すボタンが出る。
- コンソールから送るとすぐに、確認の答えなら秘書に渡ると、秘書が考えていることが会話の終わりに出る。道具を使っているあいだは、していることが言葉で出て、先の仕事を待っているなら、そう出る。秘書が答えるか、その入力のターンが終わると消える。主人の答えを待っていることは、この表示ではなく確認のカードで出る。
- この表示は、頁を開き直しても、ほかの端末で開いても、続いているあいだは出る。秘書に 30 分動きがなければ消える。
- 発言は Markdown として書式つきで出る。改行はそのまま改行になり、Slack の書き方の太字・取り消し線・リンクもそのとおりに出る。
- 主人か秘書の発言に、公開されている頁の URL があれば、本文の下に、その頁が名乗る題・説明・サイトの名前・画像がカードで出る。1 つの発言に出るカードの数には上限がある。頁が名乗らないもの、ログインの要るもの、私的なネットワークの中を指すものは、リンクのまま出る。
- カードのために頁と画像を読むのは Famulen で、ブラウザは読まない。どの外の展開サービスにも URL を渡さない。秘書の発言にある URL は、秘書の組み込みの道具 `WebFetch` の権限が許可か自動のときだけ読む。
- 発言ごとに、そのときのワークグループで道具の可否が決まる。
- 秘書が途中で止まり、外への呼び出しが終わったか分からない発言は、「途中で切れた依頼」のカードとして出る。主人が「続ける」を選ぶと渡し直し、「やめる」を選ぶと取りやめる。
- 秘書の発言には、右のタブを開くボタンが付くことがある。秘書が勝手にタブを切り替えることはない。
- [確認](tool-permissions.md#確認)は会話の中にカードとして出て、その場で答えられる。

Famulen の本体が起動し直すとき、開いている頁はそのまま残り、戻ると続きから使える。待っている間に送った変更は、送り直されずに失敗として出る。

## Even G2

- 主人のスマートフォンの Even App で、コンソールの頁の一つを開くと、Even G2 にコンソールが出る。開けるのは、コンソールを開けるところからだけ。Even Hub には出していないので、Even App の開発者向けの読み込みで開く。開き方は設定の「チャネル」に出る。
- 眼鏡が最初に出すのは、最後に使った話の会話。タップで話し、上下で会話をさかのぼる。長い発言は区切って出し、どこを読んでいるかが分かる。ダブルタップで一つ戻り、会話では眼鏡の終了の確かめが出る。
- 長押しで、会話・今日の予定・タスク・確認・メモのメニューが開き、選んでいる項目の中身の一部が横に出る。開くと一覧になり、会話からは話を選び直すか、新しい話を始める。
- 選んでいるものは明るさだけで示す。操作の説明は出さない。聞き取っているあいだと秘書が考えているあいだは、点が増えていく。
- 話しかけた声は、[声の聞き取り](models.md#役割)のモデルが文字にし、コンソールに書いたのと同じく、開いている話に入る。発言は Even G2 から来たものとして並ぶ。黙ると少しして送り、タップでもすぐ送る。ダブルタップでやめる。何も聞き取れなければ、何も送らない。聞き取っているあいだも、それまでの言葉が出る。
- 予定・タスク・メモの項目を選んでタップすると、その項目を添えて話せる。タスクは、済にすることも、秘書に任せることもできる。
- [確認](tool-permissions.md#確認)は、何をするかと渡すものを省かずに出し、長ければ区切って出す。メニューの「確認」から答えられる。開いている話に確認が一つだけ出ているときは、「はい」や「やめて」で始まる言葉を声で言うと、それがその確認への答えになり、言葉は発言としても届く。
- 声の聞き取りにモデルがないとき、その日の上限に達したとき、話しかけを送れなかったときは、眼鏡にそう出る。

## 通知

- 主人は、設定の「通知」の頁で、開いているブラウザかホーム画面に足したアプリで通知を受け取るようにできる。https（か localhost）で開いていることが要る。iPhone と iPad では、ホーム画面に足したアプリだけが受け取れる。
- 秘書や手代のどの[確認](tool-permissions.md#確認)も、出たときに、受け取る端末すべてに通知を送る。送れなければ、答えを待つあいだに何度か送り直す。コンソールを閉じていても届く。Slack で尋ねた確認も、ほかの場所で答え終えた通知も、端末からは消えない。
- 通知を開くと、コンソールの会話にその確認が出て、そこで答えられる。通知そのものからは答えられない。開いたときに答え終えていれば、そう伝える。
- 通知に載せることは、番号だけ、何をするか（既定）、中身まで、から主人が選ぶ。何をするかは、道具の名前ではなく、つなぎ先の名前と言葉で書く。中身まで載せるときも、秘密が出うると見える確認と、つなぎ先の道具でない呼び出し（シェルのコマンドなど）では、何をするかだけを載せる。
- 通知は[ゲートウェイ](../../crates/gateway/SPEC.md#持ち主の端末への通知)を通り、ブラウザの配送サーバー（Apple や Google など）を経て届く。中身は配送サーバーには読めない。
- 主人は、受け取る端末を見て、外し、開いている端末に試しに送れる。もう受け取らない端末は一覧から消え、その端末でコンソールを開いたときにそう伝える。送れなかった端末には、一覧にそう出る。秘書は、端末や載せることを変える道具を持たない。

## セクション

- ホーム：その日の要約（いまか次の予定、主人を待っているものの数、その日の件数）と、タイル。タイルは、足す・外すことができ、マス目の好きなところに、好きな大きさで置ける。置いた場所にほかのタイルがあれば、そのタイルが下へよける。配置は残る。狭い画面では、上から順に一列に並ぶ。タイルは今日の予定、確認待ち、秘書が進めている仕事、タスク、最近のメモ、期限の近い物と契約。
  - 秘書が進めている仕事は、動いているもの、待っているもの、これからのものに分かれる。動いているのは、進行中のタスクと実行中の委託だけ。作業記憶は出ない。
- カレンダー：日・週・月で予定を出す（[カレンダー](calendars.md)）。枠に入りきらない予定も、ポインタを重ねると全文が読める。何日かにわたる予定は、かかる日のすべてに出る。タスクの期限と仮押さえも、その日の欄に出る。
- タスク・メモ・相手・物・契約：[記録](records.md)のとおり。委ねたタスクは[手代](worker.md#コンソール)のとおり。
- 記憶：[記憶](memory.md)のとおり。
- 設定：[設定](config.md#コンソールで決めるもの)のとおり。[役](roles.md)ごとの頁は、その役のモデル・考える深さ・1 日の上限と、その役だけの設定を持つ。

### 消すときと保存するとき

- 手で戻せないもの（記録、つながり、鍵、動いている仕事など）を消す・外す・やめる前に、必ず尋ねる。ラベルやタイルのように、選び直せば戻るものは尋ねない。
- 選ぶもの・切り替え・数・短い文は、決めたときに保存される。備考や記憶のような長い文、足す画面、金庫に入れるものは、ボタンで保存する。
- 読めなかったときは、わけと、読み直すボタンが出る。
- 押したものは一度だけ届く。届くまでボタンは灰色になって押せず、承認と却下のように同じものに向けたボタンは一緒に止まる。届かなかったときは、わけが出て、押し直せる。

## 状態とログ

- 右の画面の上の帯に、秘書が考えているか待っているかと、主人を待っているものの数を出す。押すと、していること、主人を待っているもの、これからの予定と最近の入力が開く。届いた入力は、すべて JSON Lines で書き出せる。
- 秘書・夢・見張り・トリアージ・見極めは、それぞれの頁の「ログを見る」から、その役が何をしたかを読む。[ゲートウェイの控え](gateway.md#控え)は金庫の頁から開く。
- どのログも新しい順に区切って並び、古いほうと新しいほうの頁へ送れる。一つのやりとりは二つの頁に分かれない。

## テストで押さえること

- localhost・設定したホスト名以外の Host は断られる
- ほかのサイトからの変更（Origin が違う POST）は断られる
- Git の通信は Origin がなくても通り、ほかのサイトの Origin があれば断られる
- 話を開いて書いたことは、返信を押さなくてもその会話に入り、一覧から書けば新しい会話になる
- 一覧には題・最後の発言・未読・答え待ちが出て、開くと、ほかの画面でも未読でなくなる
- 開いていない話に届いたものは知らせに出て、開いている話は動かない
- 確認は尋ねた話にだけ出る。委ねた仕事の確認は、頼んだ話に出る
- 打ちかけの文は話ごとに残り、送り先を替えると付いていく
- コンソールから送った発言は、ワークグループと見ていた画面を添えた入力になる
- 会話に添えた項目は、発言の入力に添えられる
- 返信は返信先の id を持ち、返信先の文が秘書への入力に引用される
- 返信への返信は同じスレッドに入り、返信への秘書の返事も同じスレッドと会話の両方に出る
- ない発言への返信は断られる
- 返信先の引用を押すと、読み込んでいない古い発言でも、読み込んで移る
- スレッドを開いても、そこで返信しても、閉じても、会話の読んでいるところは動かない
- ほかのワークグループの発言は、返信先の引用・返信の数・スレッドに出ない
- 項目を開いただけでは、入力欄に札は付かない
- 選んだ・貼った・落としたファイルは、発言の入力に添えられ、会話に出る
- 受け取れないファイルは、わけが出て、外すまで送れない
- 添えたファイルの中身は、開いても動かない
- 秘書のコンソールへの発言と確認は、開いている画面に押し出される
- 性別を選ぶと、開いているどのタブのアイコンも替わり、次に開いた頁は初めからそのアイコンで届く
- 確認にコンソールで答えると、Slack の確認も答え済みになる
- 確認が出ると、受け取る端末すべてに 1 度だけ通知が届く
- 通知に載せることは主人が選べ、中身まで載せるときも、秘密が出うる確認の中身は載らない
- 通知の文に道具の名前は出ない
- もう受け取らない端末は一覧から消え、送れなかった端末にはわけが残る
