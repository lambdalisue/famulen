# コンセプト

Famulen が何を目指し、どんな考えで設計を判断するかを書く。考えが変わればこの文書をその場で書き換え、そこから下した判断は ADR に記録する。

## Famulen とは

一人の主人に仕える、執事や秘書、補佐官と呼ばれるような存在を目指すもの。主人は秘書と話しながら仕事を投げ、秘書はそれを裏で最後までやり遂げ、主人が目を向けるべきことを知らせる。秘書の名前は主人が付ける。Famulen はそれを動かす仕組みの名前である。

名前はラテン語の famulus から来ている。主人の身の回りに仕える付き人や助手のことで、ファウストに仕えた助手ワーグナーがそう呼ばれる。Famulen は秘書という存在の種類の名前で、一人ひとりの秘書には主人が名前を付ける（「Famulen のミナ」）。主役は主人で、秘書はその傍らで主人の仕事を片づける。

主人がふだん向き合うのはコンソールという画面である。左で秘書と話し、右で予定・タスク・メモ・相手・物・契約を見る。システム手帳のように、セクションを開いて見ながら話せる。Slack や眼鏡など、ほかのチャネルから話しかけても、同じ秘書が同じ手帳と記憶で応じる。

その中身は、既存のモデル CLI を動かす AI エージェントのハーネスである。

## 誰のためのものか

自分専用の秘書を持ちたい一人の人。仕事がいくつものサービスといくつものアカウントに散らばっていて、思いついた仕事を雑に投げておけば、あとは勝手に片づいていてほしい人。自分から尋ねるより知らされるほうを好む。Famulen は自分のマシンで自分で動かす。

## 原則

- <strong>一人の主人に仕える。</strong>主人が許した友人の頼みにも応じるが、執事と同じく応じ方を変え、主人の秘密を漏らすことはない。
- <strong>仕事は最後まで持つ。</strong>雑な頼みでも意図を汲み、片づくまで手放さない。主人のタスクと秘書の仕事は一つの並びにあり、どちらがやってもよい。
- <strong>頼まれるのを待たない。</strong>外で起きたことを見張り、割り込むだけの価値があるときにだけ話す。見張りは届いたものを小さなモデルでまとめて読み分け、秘書の賢いモデルには本当に要るものだけを渡す。
- <strong>見ているものを分かち合う。</strong>主人が画面で見ているものは秘書にも伝わり、「これ」で話が通じる。
- <strong>手綱はハーネスが握る。</strong>エージェントにできることは、プロンプトではなくハーネスが決める。
- <strong>記録と記憶を分ける。</strong>主人が頼りにする事実は記録として持ち、秘書が覚えたことは記憶として持つ。どちらも主人が中を見て直せる場所に置く。
- <strong>記憶は眠って整える。</strong>昼は書き留め、夜に夢を見て整理する。主人の言葉も間違うことがあるが、覆すには確かな根拠を要する。
- <strong>既存のモデル CLI の上に建てる。</strong>エージェントループは作り直さない。モデルは差し替えられ、役割ごとに安いものと賢いものを使い分ける。

## しないこと

- チームで共有するアシスタントになること。友人の頼みに応じても、仕える相手は主人だけである。
- 自前のモデルループを回すこと。
- 特定のモデルの提供元だけに頼ること。サービスとのつながりも、Famulen が主人のアカウントごとに持つ。
