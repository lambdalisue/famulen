# 契約は、それを知らせるメールの出来事を手帳の外に貯め、その全体から導いて手帳に書く

状態：採用

## 背景

購読や回線などの契約は、一通のメールでは決まらない。毎月の請求、更新、解約の知らせが何通も届き、続いているかどうかは、いちばん新しい知らせと、その後に何も届かないことから分かる。過去のメールと届いたばかりのメールは並んで読まれ、古い順に読めるとは限らない。

契約の知らせを見分けて読む仕組みは、買った物と同じにできる（`20261125-add-what-the-owner-bought-from-mail-the-lookout-marks-without-giving-the-lookout-tools.md`）。

## 決定

メールを読むモデルは、一通が知らせる出来事だけを答える。出来事は手帳の外に貯め、同じ契約のものすべてから、契約の状態と中身を Famulen が導いて手帳に書く。確かなことが言えなければ、続いているとは書かない。足す前に主人に確かめない。

## 検討した他の案

- 買った物のように、メールを読むたびに記録の状態を進める。読む順で結果が変わり、請求が途絶えたことを表せない。
- 出来事を手帳の契約に並べて持つ。毎月の請求で手帳が埋まり、主人が頼る事実が読みにくくなる。
- モデルに契約の状態を答えさせる。一通しか読まないモデルには分からず、日が経って変わることも表せない。

## 結果

- 同じ契約と見分けた出来事からは、読む順によらず同じ記録になる。
- 日が経つだけで、契約の状態が変わることがある。
- 偽の知らせが起こせるのは、契約が一つ増えることと、メールから足した契約の中身が変わることまで。
- 手帳だけからは、どのメールから導いたかをたどれない。
