# コンソールは私的なネットワークの内側にだけ開き、ログインを持たない

状態：採用

## 背景

コンソールに入れる人は、主人の記録と記憶を読めるうえに、エージェントに許すことまで変えられる。Famulen は一人の主人のためのもので、ログインの仕組みを持つと作りが大きくなる。

## 決定

コンソールと API は、Tailscale などの私的なネットワークか localhost にだけ開き、Famulen 自身はログインの仕組みを持たない。

## 検討した他の案

- ログインを作り、インターネットに開く。守るものが増え、主人一人には過剰である。

## 結果

- 決めたホスト名以外での接続と、ほかのサイトからの変更は断る。
- 外のサービスへのログイン（OAuth）の戻り先も、このコンソールになる。
- ゲートウェイの受け口は、コンソールとは別の番地で待ち受ける。そこにどこから届くようにするかは、主人が決める。
