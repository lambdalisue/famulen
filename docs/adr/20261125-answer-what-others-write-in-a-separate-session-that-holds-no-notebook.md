# 主人以外の言葉を含む入力には、手帳を持たない別のセッションで答える

状態：採用

## 背景

手帳には主人の個人情報・契約・人の記録・仕事の機密がある。Slack では主人以外の人も秘書に話しかける。秘書は常駐する一つの会話を続けていて、主人と話した中身や読んだ記録がその会話に残っている。手帳の道具をその場だけ断っても、会話に残ったものから漏れる。

## 決定

主人以外の人の言葉を含む入力は、常駐の会話に渡さず、入力ごとの使い捨てのセッションで答える。そのセッションは、手帳も記憶も、届いた場所への返事と主人への問い合わせのほかの道具も持たない。主人の発言に他の人の言葉が添えられたものも、同じに扱う。手帳で答えてよいかは主人が問いごとに決め、許したときだけ、常駐の秘書が読むことと、その場所へ答えることだけをできるターンで答える。

主人のために外の出来事を判断する見張りの入力は、手帳を使ってよい。代わりに、外へ出すことはすべて主人の確認になる。

## 検討した他の案

- 指示の文章だけで禁じる。相手の言葉に乗せられると破られ、守られたかを確かめられない。
- 常駐の会話のまま、手帳の道具だけを断る。会話に残っている手帳の中身から漏れる。
- 見張りの入力でも手帳を塞ぐ。タスクに足すことも、記録と照らして知らせることもできなくなる。
- 主人以外の人には、手帳に関わる問いを一律に断る。教えてよいものまで、主人が自分で答えることになる。

## 結果

- 主人以外の人との会話は、常駐の秘書の会話に残らず、続きの発言も前の話を知らずに答える。
- 注視しているチャンネルで、他の人の言葉が添えられた主人の発言には、手帳を使わずに答える。主人はメンションか DM で頼み直す。
- 見張りの入力から外へ書くことは、常に許した道具でも確認になる。
