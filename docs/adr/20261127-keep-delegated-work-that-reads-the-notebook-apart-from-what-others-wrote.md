# 手帳を読む仕事は、他人が書いたものと外へ出す道具から、始める時点で分ける

状態：採用

## 背景

委ねた仕事に手帳を読ませ、つなぎ先の道具やウェブも渡すと、一つのモデルが、主人の機密と、他人が書いた文面と、外へ送る手段を同時に持つ。文面に書かれた指示に従えば、機密が外へ出る。

## 決定

手帳を渡した仕事には、他人が書いたものを読む道具と自由な通信を、初期設定で渡さない。両方が要る仕事は、始まる前に主人が確認する。始まったあとに外の文面を読んだ仕事は、手帳を新しく読めなくなり、外へ出す道具は確認になる。

## 検討した他の案

- 呼び出しのたびに中身を調べて、機密が出るものを止める。言い換えや分割で抜けられ、見分けられるとは約束できない。
- 外の文面を読んだ時点で分けるだけにする。モデルがすでに読んだ手帳の中身は消せず、シェルで読んだ外の文面は見つけ切れない。
- 手帳と他人の文面を同じ仕事に決して渡さない。メールや Issue を読んで手帳の事情に照らす仕事が委ねられなくなる。

## 結果

- 機密を守る主な手立ては、始める時点で渡すものを分けることと、主人の確認になる。
- 始まったあとの制限は補いで、シェルで読んだ外の文面には効かない。
