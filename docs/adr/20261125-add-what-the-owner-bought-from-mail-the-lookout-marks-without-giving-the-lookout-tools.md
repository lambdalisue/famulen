# 買った物は、見張りが見分けたメールを取り込みが読んで手帳に足し、見張りには書かせない

状態：採用

## 背景

主人は、買った物を手で書かなくても手帳に残ってほしい。買い物の店は、買い手が自分の注文を読む API を出しておらず、ログインした画面をプログラムで読むことを規約で禁じる店もある。注文や発送の知らせは、すでに見張りが受けているメールに届いている。メールは多く、ほとんどは買い物の知らせではない。

見張りは外から届いた文面を読むので、道具を持たず、手帳に書かない。届いた文面に指示が書かれていても、何も起こらないようにするためである。

## 決定

見張りは、届いたメールを読み分けるその一度で、買い物の知らせがどれかも答える。それらの本文は、秘書の取り込みが道具を持たないモデルに読ませ、答えから決まった形の記録（物）だけを Famulen が足し、直す。足す前に主人に確かめない。

## 検討した他の案

- 店ごとに画面を読み取る。規約に触れ、画面が変わるたびに壊れ、合言葉を預けることになる。
- 見張りが渡した知らせを、秘書が読んで道具で足す。賢いモデルを買い物のたびに呼び、届いた文面を、道具を持つモデルに読ませることになる。
- 足す前に主人に一件ずつ確かめる。件数が多く、続かない。
- 主人が店の差出人を決めておく。書き直さなければ古くなり、書いていない店の買い物が漏れる。

## 結果

- 店ごとのつなぎ方も、店の一覧も持たない。メールの届く店なら、どこの買い物も入る。
- 偽の買い物の知らせが起こせるのは、物が一つ増えることと、同じ注文の物の状態が変わることまで。
- メールに品名のない買い物は、物にならない。
- 物でないものや重なったものが入ることがあり、あとから整える。夢は、確かに重なった物をまとめる。
