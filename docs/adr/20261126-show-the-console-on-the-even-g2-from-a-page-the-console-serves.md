# Even G2 には、コンソールが出す頁を Even App で開いてコンソールを出す

状態：採用

## 背景

主人は Even G2 から秘書と話し、その場で予定やタスクや確認を見たい。G2 で動くものは、主人のスマートフォンの Even App が開く Web の頁で、頁が眼鏡に描き、眼鏡のマイクの音を受け取る。頁がどこから来るかは、開く URL で決まる。

コンソールと API にはログインがなく、私的なネットワークの内側にだけ開いている。主人のスマートフォンは、コンソールをホーム画面に置いて、その網の中から開いている。

## 決定

G2 の頁はコンソールが自分の番地で出し、主人は Even App でそれを開く。頁はコンソールの画面と同じ API を、同じ番地から呼ぶ。話しかけた声は、頁が本体に送り、声の聞き取りの役のモデルが文字にする。

## 検討した他の案

- G2 をゲートウェイのチャネルにし、受け口に話しかけを届けさせる。チャネルが受けるのは話しかけだけで、予定・タスク・確認・メモを見る画面を持てない。眼鏡から受け口に届かせるには、合言葉と、私的なネットワークの外から届く口が要る。
- Even Hub にアプリとして出し、公開された番地から本体へ通わせる。本体をインターネットに開くか、取り次ぎの場所と秘密を新しく持つことになる。
- 声を Even App の聞き取りか、スマートフォンの音声認識に任せる。頁からは使えず、どのモデルにいくら使うかを主人が決められない。

## 結果

- G2 から話せるのは、スマートフォンが私的なネットワークの中にいるときだけ。新しい口も秘密も増えない。
- G2 の頁は Even Hub に出さない。主人は Even App の開発者向けの読み込みで開く。
- 声を文字にするには、文字起こしのモデルを登録して、声の聞き取りの役に割り当てる。
- 眼鏡でできることは、コンソールの API にあるものに限られる。
