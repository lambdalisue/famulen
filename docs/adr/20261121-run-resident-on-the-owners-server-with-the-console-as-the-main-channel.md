# 主人のサーバーに常駐し、コンソールを主なチャネルにする

状態：採用

## 背景

主人は秘書と話しながら、予定・タスク・相手・記憶などを見て直したい。チャットだけでは見るものが流れてしまい、管理画面だけでは話せない。Slack や眼鏡からも話しかけたい。Famulen は主人のアカウントと記憶に触れるので、主人の手元で動く必要がある。

## 決定

Famulen は、主人が管理するサーバーに常駐する。本体（API と秘書のセッションを持つもの）とコンソールを、コンテナとして並べて動かす。主なチャネルはコンソールで、左に秘書との会話、右に主人の記録と記憶を出す。Slack などはほかのチャネルとしてつなぎ、どこから話しかけても同じ会話が続く。

## 検討した他の案

- Slack を主なチャネルにし、Web は管理だけにする。会話しながら見るものを並べられず、記録を直すのに画面を行き来する。
- チャネルごとに本体を分ける。会話と記憶が分かれる。

## 結果

- コンソールと Slack は、同じ入力の受け口と同じセッションに入る。
- Slack とは Famulen の側からつなぐので、外から届く公開の入口がなくても使える。
