# コードの委託を、名指した一つのリポジトリでだけ直接動かして試し、主人の答えを待たせる

状態：採用

## 背景

コードを変える委託は、Adroit のセッションに任せている。Famulen はすでに手代として Claude Code を自分で始め、実行役の下で動かしているが、手代は主人に何も尋ねられず、確認の要る道具は断られる。コードの仕事は、ビルドやテストのためのシェルと、迷ったときの主人の一言を欠かせない。

Famulen の API とコンソールにはまだ認証がなく、同じ利用者で動くエージェントは、砂場の外ではそれらに届く。

## 決定

Famulen が自分で始める Claude Code に、コードの仕事を直接させる実行先 `direct` を足す。主人が設定で名指した一つのリポジトリでだけ動き、名指しがなければどこでも動かない。委ねる先の既定は Adroit で、Famulen が仕上げまで持てるリポジトリに限り、主人が設定で直接に替えられる。

- 仕事ごとに、Famulen がそのリポジトリに jj の作業場所を作り、そこで動かす。作業場所は仕事が終わっても残す。
- 主人の確認が要る呼び出しは、断らずに、ほかの呼び出しと同じ確認として主人に出し、答えまで待つ。権限の判定は手代と同じものを使う。エージェントが主人に尋ねることも、答えまで待つ。
- 会話の id は始める前に Famulen が決めて残す。実行役ごと切れたら、その会話を探して続ける。
- エージェントのシェルは砂場の中で動き、Famulen の API、コンソール、手帳、封じた場所、ほかの手代の仕事の場所、このマシンのどのソケットにも届かない。書けるのは作業場所と、jj と Git がリポジトリに書く場所だけ。そのうち、主人が次にリポジトリや作業場所を使うときに主人として動く設定とフック（jj と Git のもの、作業場所と仕事のディレクトリに置く Claude Code のもの）は書けない。ファイルの道具は、作業場所のどの深さの Claude Code の設定も書けない。変更したコードそのものは、主人が確かめてから動かす。

## 検討した他の案

- 直接実行を、仕上げを持てないリポジトリでも既定にする。仕上げに Adroit のセッションが要る。
- 手代を広げ、コードの仕事も道具と確認なしでさせる。シェルとファイルの書き込みが確認になることが多く、仕事が途中で止まる。
- 作業場所をエージェント自身に作らせる。エージェントのシェルにリポジトリの外を書かせることになり、どこで働いたかを Famulen が知れない。
- 会話の id をエージェントが名乗るのを待って残す。名乗る前に実行役ごと切れると、続ける会話が分からない。

## 結果

- 名指したリポジトリのコードの仕事は、Adroit なしで終わりまで動き、主人は回の頁と確認で答えられる。名指しを消せば、直接の委託は始まらなくなる。
- 主人の答えを待つあいだも、仕事の長さの限りは数える。
- エージェントは push、PR、マージをしない。主人が仕上げを許していないリポジトリでは、変更は作業場所に残り、その先は主人か Adroit のセッションが持つ。
- 作業場所の片づけは、Adroit の作業場所の片づけと別に要る。
- 書けない場所を砂場が塞ぐと確かめたのは macOS の上だけなので、試しは macOS の上でだけ動かす。
- エージェントは主人と同じ jj のリポジトリを使うので、jj の操作として主人の作業コピーの変更も書き換えうる。これは囲いでは塞げず、試しのあいだはリポジトリを一つに限ることで小さくする。
