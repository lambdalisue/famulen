# 公開と確かめられないものは、すべて機密に数える

状態：採用

## 背景

主人は勤め先の情報のほとんどを読める。秘書がつなぎ先（コードの置き場、社内の wiki、タスクの道具、汎用の API や MCP）で読むものには、社外に出してはならないものが多い。

機密に数えるものを並べていたので、並べたものの外は、新しく足したつなぎ先も含めて、何を読んでも公開の場へ確認なしで出せた。

## 決定

秘書が読んだもののうち、Famulen が公開と確かめられるものだけを機密から除き、ほかはすべて機密に数える。公開と確かめるのは、誰もがアカウントなしで同じものを読めると、道具と呼び出しと、その場でアカウントなしに尋ねた答えから分かるときだけ。社内の誰もが読めても、社外の人が読めないものは公開としない。

## 検討した他の案

- 機密に数えるものを並べ続ける。新しいつなぎ先や道具のたびに並べ足すことになり、足し忘れたものは漏れる。
- つなぎ先ごとに、主人が機密かどうかを選ぶ。選ばなかったものの扱いがまた問題になり、一つのつなぎ先の中に公開と非公開が混ざるもの（公開と非公開のリポジトリなど）を分けられない。
- 秘書のモデルに、読んだものが公開かを判断させる。漏れたときに、モデルの判断のほかに確かめた跡が残らない。

## 結果

- 新しいつなぎ先と道具は、何もしなければ機密になる。公開と扱うものを増やすには、確かめ方をコードに足す。
- 公開か確かめるために、アカウントなしで外に尋ねることがある。尋ねられなかったときは機密になる。
- 公開の場への返事で確認が出ることが増える。機密を読んでいない返事は、これまでどおり確認にならない。
