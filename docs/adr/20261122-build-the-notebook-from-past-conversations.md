# 過去のやりとりから手帳を作り、使い始めから主人を知る

状態：採用

## 背景

秘書が主人の役に立つのは、主人の好み・相手・約束を知ってからである。会話から少しずつ覚えるだけでは、使い始めてしばらくは何も知らない秘書のままになる。主人の Slack、メール、AI との会話には、そのための材料が何年分もある。

## 決定

主人の Slack の履歴、メール、AI との過去の会話から手帳を作る。取り込んだやりとりは、古い順に、その日付の気づきとして書き、夢で整理する。取り込みで得た記憶は推し量ったものとして扱い、心得に入る前に主人が目を通す。

## 検討した他の案

- 会話から覚えるのを待つ。使い始めの秘書が主人を知らず、主人が同じことを何度も教えることになる。
- 取り込み専用の整理の仕組みを別に作る。夢と同じ判断を二通りに持つことになり、記憶の入り方が割れる。

## 結果

- 使い始めてすぐに、秘書は主人の好みと相手を知っている。
- 取り込みはモデルを多く使うので、モデルの役割と 1 日の上限を持ち、何日かに分けて進む。
- 取り込んだ記憶は、確かめられるまで推し量ったものとして扱われる。
- 相手が書いた文面はそのまま手帳に残さない。
