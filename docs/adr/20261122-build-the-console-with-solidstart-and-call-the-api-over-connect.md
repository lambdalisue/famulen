# コンソールは SolidStart で作り、API を Connect で呼ぶ

状態：採用

## 背景

コンソールは、会話の欄を残したまま右の画面を行き来し、予定やタイルを並べ替え、選んだ値をその場で保存する、アプリとしての画面である。ブラウザで細かく変わる画面と、開いてすぐ読める最初の表示の両方が要る。

## 決定

コンソールは SolidJS の SolidStart で作る。最初の表示はサーバーで描き、そのあとはブラウザでアプリとして動く。データはすべて Famulen の API から Connect で取り、変化は API の配信で受け取る。

## 検討した他の案

- サーバーで HTML を作り、htmx で一部を差し替える。動きを足すたびにブラウザ側の手当てが増え、すき間から不具合が出る。
- サーバーで描かず、ブラウザだけで描く。配る物が一つ減るほかに得がなく、最初の表示が遅くなる。
- React で作る。画面の一部だけを細かく更新する作りの SolidJS の方が、会話の流れ込みや並べ替えに素直に合う。

## 結果

- コンソールは、Famulen の本体とは別のプロセスとして動く。
- 画面の振る舞いは、本物のブラウザで操作するテストで確かめる。
