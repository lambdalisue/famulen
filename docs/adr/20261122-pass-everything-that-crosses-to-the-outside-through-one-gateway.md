# 外とのやりとりは、すべてゲートウェイ 1 つを通す

状態：採用

## 背景

見張り、カレンダー、確認、コンソール、秘書のモデル CLI は、どれも外のサービスを呼ぶ。呼ぶ側ごとに外への道を持つと、主人の決めた権限が届かない道が残り、モデルを差し替えると道具の届き方まで変わる。

## 決定

Famulen が外のサービスとやりとりする口は、ゲートウェイ 1 つにする。秘書、手代、見張り、記録、カレンダー、チャネルは、どれもゲートウェイを呼んで外とやりとりする。秘書のモデル CLI には外の MCP サーバーを直接渡さず、claude.ai でつないだコネクタも使わない。モデルの頼みで出る呼び出しは、ゲートウェイで主人の決めた権限に裁かれる。

## 検討した他の案

- 呼ぶ側ごとに外を呼ぶ。権限の抜け道が残り、サービスごとの扱いが呼ぶ側に散らばる。
- claude.ai のコネクタを、ゲートウェイの通り道の一つにする。Claude Code を一度動かさないと呼べないので、遅く、トークンを使い、壊れやすい。つなげるのも 1 つのサービスに 1 アカウントだけで、モデルを Claude から替えると使えなくなる。

## 結果

- 権限は、どこから出る呼び出しにも同じように効く。
- モデルを差し替えても、外の道具はそのまま同じに使える。
- 外のサービスごとの呼び方と受け方は、ゲートウェイの中に閉じる。
