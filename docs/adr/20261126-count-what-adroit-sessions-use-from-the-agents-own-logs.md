# Adroit のセッションが使った量は、エージェントが残す記録から数える

状態：採用

## 背景

委ねた仕事の多くは Adroit のセッションで動き、利用枠の多くを使う。Famulen がその場でモデルを呼ぶのではないので、使った量は Famulen を通らない。Adroit は、セッションが使った量も、セッションがどの会話を持つかも外に出さない。

## 決定

Adroit のセッションが使った量は、Claude Code と Codex がこのマシンに残す会話の記録から数える。記録のうち Famulen が残すのは、トークンの数と、それを答えたモデルと時刻だけにする。

どの会話がどの委託のものかは、委託がセッションに付ける名で見分ける。

## 検討した他の案

- Adroit が出すようになるのを待つ。それまで何も見えず、これまでの分も数えられない。
- セッションが終わったときに、働き手に使った量を書かせる。働き手は自分の使った量を知らず、途中で止まったものや、あとから続いたものは数えられない。
- 定額の枠の残りの割合から見積もる。主人自身の仕事と分けられず、委託ごとにも分からない。

## 結果

- 別のマシンの Adroit や、Claude Code と Codex のほかのエージェントの分は数えられない。
- 会話の記録の形が変われば、読み方も変える。
- 記録が消える前なら、過ぎた委託の分も数えられる。
