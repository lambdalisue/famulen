# 秘書は主人のスキルを使えるが、許可の決まりは受け継がない

状態：採用

## 背景

主人は、自分の作業に使っているスキル（ノートの書き方、記憶の扱い方など）を、秘書にも使ってほしい。一方で、主人の Claude Code の設定には道具を許す決まりがあり、それが秘書に効くと、Famulen の確認を通らずに道具が動く。スキルの中にも、書かれた道具を尋ねずに動かす `allowed-tools` や、尋ねずにコマンドを動かすフックがある。

## 決定

秘書は主人のスキルをすべて使える。Famulen は起動のたびに、主人のスキルと、有効にしたプラグインのスキルを秘書の作業場所に写し、写すときに、道具を許す記述とフックを取り除く。主人の設定のうち、道具を許す決まりは秘書に渡さない。スキルから呼ばれる道具も、ほかの道具と同じく呼ぶたびに Famulen が裁く。

## 検討した他の案

- 主人の設定をそのまま読ませる。スキルは使えるが、許す決まりもフックも効き、確認を通らずに道具が動く。
- スキルを写さず、作業場所から主人のスキルへリンクを張るだけにする。スキルの許す記述がそのまま効き、確認を通らない道具の実行ができる。
- 秘書に使わせるスキルを主人が一つずつ選ぶ。主人が求めたのは制限のないことで、選ぶ手間に見合う守りは、許す記述を取り除くことで得られる。

## 結果

- 主人がスキルを足したり直したりすると、秘書は次に起動したときにそれを使う。
- スキルが尋ねずに動かすつもりの道具も、秘書では主人に尋ねる（または主人が道具の頁で決めたとおりになる）。
- スキルが作業場所の外に書くには、主人がその場所を秘書の書ける場所に足す。
