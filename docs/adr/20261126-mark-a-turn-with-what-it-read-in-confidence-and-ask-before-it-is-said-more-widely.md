# 機密を読んだターンに印を付け、印より広い場へ言う前に主人に確認する

状態：採用

## 背景

主人が公開の場で秘書に頼んだことへの答えには、主人の手帳にある人の評価や、公開でない場のやりとりが混ざりうる。主人以外の人の言葉を含む入力は手帳を持たないセッションで答えるが、主人の頼みは手帳と非公開のやりとりを読むので、それでは防げない。一方、公開の場で答えないことにすると、機密のない返事まで使えなくなる。

## 決定

秘書が読んだものの種類と読んだ場を、そのターンに印として残す。印の範囲より広い場へ言うものは、送る前に主人に確認する。何が機密か、どこが広いかは、読んだ道具と Slack の情報からモデルを使わずに決め、決められない場は公開とする。

前のターンで読んだものは常駐の会話に残り、印では追えない。印のないターンでは、送る文をモデルが読み、機密を含みそうなものだけを確認にする。主人の言葉での許しもモデルが探すが、主人の発言にその言葉がそのままあるときだけ認める。

## 検討した他の案

- 公開の場では一律に答えない。漏れるものがない返事まで主人が書くことになる。
- 指示の文章だけで禁じる。守られたかを確かめられない。
- 印を会話が続くかぎり残す。ほとんどの発言が確認になり、主人が中身を読まずに承認するようになる。
- すべての発言をモデルだけで判断する。読んだことがはっきりしているものまで、モデルの見落としに任せることになる。

## 結果

- 機密を読んでいない返事でも、主人との DM のほかへ書くたびにモデルを使う。モデルが使えないあいだは、どれも確認になる。
- 機密を読んだだけで、送る文に機密がなくても確認になる。
- 手代は何を読んだか主人に見えないまま書けるので、Slack に書かせない。
