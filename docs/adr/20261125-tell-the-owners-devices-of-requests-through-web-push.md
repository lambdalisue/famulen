# 確認が出たことは、Web Push で主人の端末に知らせる

状態：採用

## 背景

確認は、主人が答えるまで秘書の仕事を止める。開いているコンソールと Slack にしか出さないと、どちらも見ていない主人は気づかない。コンソールはログインのない私的なネットワークの中にあり、主人はそれをスマートフォンのホーム画面にも置いている。

## 決定

確認が出たことは、コンソールを足したブラウザとホーム画面のアプリに、Web Push で知らせる。答えるのはコンソールで、通知そのものからは答えさせない。

## 検討した他の案

- 通知のためのほかのアプリやサービスを使う。主人がもう一つのアプリを入れて預け先を信じることになり、開いてもコンソールに戻らない。
- Slack の通知に任せる。Slack をつながない主人には届かず、チャンネルでは主人にだけ見える一時的な発言になるので見落とす。
- 通知のボタンで答えさせる。中身を読まずに許せてしまい、主人の iPhone では出ない。

## 結果

- 通知はブラウザの作り手の配送サーバーを通る。中身はそこでは読めないが、知らせたことと時刻は知られる。
- 通知を受け取るには、コンソールを https で開いていなければならない。
- 答える口は増えない。
