# 手帳は Famulen のサービスなしで使えるライブラリと CLI にし、Famulen はライブラリを使う

状態：採用

## 背景

手帳は、AI が読み書きする文書をどう置くかの決まりと、その決まりを守らせる道具からなる。どちらも Famulen の秘書に限らず、主人がほかの AI に扱わせる文書にも役に立つ。決まりを守らせる道具が Famulen のサービスの中にあると、サービスの外で手帳を扱う人や AI は、ファイルを直接書いて形を崩すしかない。

## 決定

手帳の決まりを守らせる道具は、Famulen から独立したライブラリ（`famulen-notebook`）として持ち、Famulen はそのライブラリを使う。ライブラリの上に、人も AI も手帳を決まりどおりに読み書きできる CLI（`famulen-notebook-cli`）を持つ。CLI は手帳だけを扱い、外のサービスにはつながない。

## 検討した他の案

- 手帳の道具を Famulen の中に置いたままにする。手帳を決まりどおりに扱うのに Famulen のサービスが要り、サービスの外では使えない。
- CLI にゲートウェイを使わせ、外のやりとりを読んで手帳を作る仕事まで持たせる。鍵や外とのつながりが CLI に入り、手帳を扱うだけの道具が重くなる。外の情報は、CLI を使う人や AI が自分で読めば足りる。

## 結果

- 手帳のライブラリは、Famulen のデータベースやワークグループを知らない。索引のような作業用の状態は、ライブラリが自分で持つ。
- 誰が手帳を書いてよいかは、使う側が決める。Famulen は秘書と主人だけに書かせる。
- 外の情報から手帳を作るのは、CLI を使う人や AI の仕事になる。AI に任せるときの手順は、CLI ではなく AI に渡す指示として持つ。
- 夢・カレンダー・ワークグループの働きは Famulen のものとして Famulen に残る。
