# 回のしたことは、確定したイベントとして台帳に残し、書きかけのものは流すだけにする

状態：採用

## 背景

委ねた仕事の様子（働き手の予定、書いたもの、道具の呼び出しと答え）は、Famulen のメモリの中だけにあった。Famulen はよく動き直すので、そのたびに予定も出力も消え、済んだ仕事が何をしたかを後から読めなかった。エージェントとは共通のイベントで話すようになり、書いている途中の断片まで受け取れる。断片は一つの発言で数百にもなる。

## 決定

回ごとに、確定したイベント（頼み、発言、道具の呼び出しと答え、ファイルの差分、問いとその裁き、予定、使用量、ターンと回の終わり）を、通し番号を付けて Famulen のデータベースの台帳に残す。予定は、変わるたびにその時の全体を残す。

書いている途中の断片（発言や道具の入力の続き、道具の途中の出力）は、画面に流すだけで台帳に残さない。確定したものが来れば、断片はそれに含まれる。

台帳には量と期間の限りを置く。古くなった回からは、予定のほかを消す。

## 検討した他の案

- 実行役が残す行をそのまま読み直す。実行役の記録は仕事が終わると片づき、Adroit の回にはそもそもない。エージェントごとの形のままなので、画面がエージェントの違いを知ることになる。
- 断片も残す。量が何十倍にもなり、読み直すたびに組み立て直すことになるが、確定したものと中身は変わらない。
- 手帳に残す。働き手の言葉は手帳に入れない、という決まりに反する。

## 結果

- Famulen が動き直しても、回の予定と出力は残り、続きから流れる。
- 画面は、台帳を読み終えてから断片を受け取る。断片を取りこぼしても、確定したもので埋まる。
- 限りを超えた分と、古い回の出力は読めなくなる。
