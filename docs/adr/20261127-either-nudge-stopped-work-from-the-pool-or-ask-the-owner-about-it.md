# 予定を残して手が止まった委託は、詰所が回数を限って促すか、主人への問いにする

状態：採用

## 背景

委ねたセッションが予定を残してターンを終えると、誰かが続きを頼むまで仕事は止まったままになる。主人は、裏で処理が進み続けることを求め、止まってよいのは、自分が答えられる問いが出ているときと、自分が止めたときだけとする。促し続ければ利用枠を使い切るので、促しには限りが要る。秘書に知らせるだけでは、秘書が動かないことがあり、主人には答える場所が出ない。

## 決定

予定を残して手が止まった委託は、モデルを持たない詰所が、秘書を通さずに、回数を限って続きを促す。促して進まないもの、促しが届かないものは、詰所が主人への問いにし、その答えで同じ委託を進めるか、やり直すか、やめる。促しは仕事の続きを頼むだけで、承認や判断の代わりにはしない。

## 検討した他の案

- 手が止まったことを秘書に届け、秘書に促させる。止まるたびにモデルの利用枠を使い、秘書が動くまで仕事も止まる。促すかどうかは、予定と状態だけで決められる。
- 進まなければ秘書に知らせて終える。秘書が何もしなければ、主人が答える場所のないまま止まり続ける。
- 届かないセッションは、問わずに新しいセッションで始め直す。前のセッションは生きたまま作業場所を持つので、二つが同じ仕事を進めうる。
- 表示だけにして、主人が促す。主人が見に来るまで仕事が進まない。

## 結果

- 予定を残した委託が黙って止まり続けるのは、主人が中断したか一時停止したとき、主人が問いをそのままにすると答えたときだけになる。
- 促してよいかは、セッションの状態と予定から決まる。ターンの返事の言い回しは読まない。判断を待つ段は、まずセッション自身に問いとして出させ、出なければ詰所が問う。
- 詰所の問いは Famulen が持つので、受け箱に出て、主人のほかは答えられない。
