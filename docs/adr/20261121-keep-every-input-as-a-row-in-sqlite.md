# 入力はすべて SQLite に 1 行として残す

状態：採用

## 背景

主人の頼みごと、予定、起床予約は、Famulen の再起動やモデル CLI の失敗をまたいで、失われてはいけない。主人はコンソールで、どの仕事がどうなったかを確かめたい。

## 決定

Famulen に届く入力は、セッションに渡す前に、SQLite の 1 行として残す。行は、渡したか、失敗したかの状態を持つ。送り主が主人か、そうでないかも行に残す。

## 検討した他の案

- 入力をメモリの中のキューだけで持つ。再起動で失われ、コンソールに出すものも残らない。
- 外部のデータベースやキューを使う。1 つのプロセスで動く Famulen には過剰で、サーバーに置くものが増える。

## 結果

- 再起動したら、渡し終えていない行から続ける。
- コンソールは、この行を読んで状態を見せる。
- 友人からの頼みのような主人でない人の言葉は、送り主の種別で扱いを分けられる。
