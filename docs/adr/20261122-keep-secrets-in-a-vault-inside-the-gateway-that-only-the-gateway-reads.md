# 秘密はゲートウェイの中の金庫に置き、中身を読めるのはゲートウェイだけにする

状態：採用

## 背景

Famulen は、つなぎ先の鍵やトークン、モデルの鍵、主人のパスワードを預かる。これらがデータベースにそのまま置かれ、API から読めると、道具を持つモデルの誰かが外の文面に促されて読み出し、外へ出してしまうおそれがある。秘書を動かすモデル CLI はファイルを読む道具も持つ。一方で、主人と秘書は秘密を足したり替えたりして管理したい。

## 決定

秘密はゲートウェイの中の金庫に置き、中身を読めるのはゲートウェイだけにする。ゲートウェイは外へ出る呼び出しのときにだけ秘密を使う。主人と秘書は、秘密を足す・置き換える・消すことはできるが、読み出すことはできない。金庫の中身は暗号にして置き、その鍵はモデル CLI に渡さない。

## 検討した他の案

- 秘密をデータベースにそのまま置き、画面で伏せるだけにする。画面の外から読めば中身が出る。
- 秘書には秘密を読ませ、使う場面を任せる。外の文面に促された秘書が、秘密を返事や外への呼び出しに書きうる。

## 結果

- 秘密を使うのは外への呼び出しだけになり、モデルの前に秘密が出ることはない。
- 主人が忘れた秘密は、Famulen から読み出せない。置き換えるしかない。
- 手帳や会話に紛れた秘密は、金庫へ移して元から消す。
- 秘密を使うモデルの呼び出しも、ゲートウェイを通る。
