# 道具の権限はつなぎ先ごとに決め、種類の既定を引き継ぐ

状態：採用

## 背景

エージェントが主人に代わって外へ働きかけるには、何をしてよいかの線が要る。主人は同じサービスでも、仕事のアカウントと個人のアカウントで扱いを変えたい。一方で、アカウントのたびに一つずつ決めるのは手間が大きい。

## 決定

道具の権限は、つなぎ先（サービスとアカウントの組）ごとに、道具ごとに主人が決める。つなぎ先で決めていない道具は、同じ種類（Gmail など）の既定に従う。

## 検討した他の案

- プロンプトで振る舞いを頼む。モデルが従う保証がない。
- 権限をサービスの種類ごとだけに持つ。仕事と個人のアカウントで扱いを分けられない。
- 権限をつなぎ先ごとだけに持つ。アカウントを足すたびに、同じことを決め直すことになる。

## 結果

- 権限はつなぎ先の頁で選び、種類の既定はその種類の頁で選ぶ。
- 種類の既定を変えると、自分で決めていないつなぎ先のすべてに効く。
