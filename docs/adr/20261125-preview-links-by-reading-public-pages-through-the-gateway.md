# 会話のリンクの先は、ゲートウェイが公開のものだけを読んで見せる

状態：採用

## 背景

会話に出た URL の先が何の頁かを、開かずに分かるようにしたい。頁は自分の題と説明と画像を名乗る（OGP）が、ブラウザからは、ほかのサイトの頁を読めない。URL は誰が書いたものか分からず、主人の私的なネットワークの中を指すこともある。

## 決定

会話のリンクの先は、ゲートウェイが、主人のアカウントを使わずに、公開のインターネットにあるものだけを読む。画像もゲートウェイが読み、コンソールは自分の番地から出す。秘書の発言にあるリンクは、秘書がウェブの頁を尋ねずに読めるときだけ読む。

## 検討した他の案

- ブラウザが読む。ほかのサイトの頁は読めない。
- 画像だけをブラウザに読ませる。仕組みは減るが、頁を書いた者が、会話を開いた時刻と主人の端末の番地を知り、主人のブラウザに私的なネットワークの中へ要求を出させられる。https のコンソールでは http の画像が出ない。
- 外の展開サービスに任せる。主人が見る URL がそのサービスに渡る。
- 秘書の発言のリンクも、いつも読む。書くだけで URL に載せたものを外へ送れるので、主人が秘書に頁を読ませないと決めた権限の抜け道になる。

## 結果

- ログインの要る頁と、私的なネットワークの中の頁は、リンクのまま出る。
- リンクの先のサイトには、Famulen を動かすマシンの番地から読まれたことが知られる。
