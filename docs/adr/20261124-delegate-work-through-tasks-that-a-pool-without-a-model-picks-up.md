# 仕事はタスクとして委ね、モデルを使わない働き手の詰所が拾って動かす

状態：採用

## 背景

秘書は重い仕事のたびに、サブエージェントか Adroit のセッションを自分で始めていた。始めた数だけ同時に動き、主人の目には、何が待っていて何が動いているかが見えなかった。秘書は始めた仕事が済んだかを自分で見に行くことになり、Famulen が動き直すと、何を始めたかが会話の中にしか残らなかった。

## 決定

ほかのエージェントに任せる仕事は、すべてタスクとして委ねる。秘書は委ねるだけで、エージェントも Adroit のセッションも自分では始めない。委ねたタスクは、モデルを使わないプログラム（詰所）が優先度の順に拾い、主人が決めた数までを同時に動かし、済んだことを秘書の入力にする。

## 検討した他の案

- 秘書が自分で始め、数を秘書に数えさせる。数も順番もモデルの判断になり、守られる保証がない。
- 委ねた仕事の並びを、タスクとは別に持つ。主人と秘書の仕事の並びが二つになり、優先度も期日もブロックも二重に要る。
- 詰所の順番をモデルに決めさせる。順番のたびに費用がかかり、同じ並びから同じ順番が出ない。

## 結果

- 主人は、委ねた仕事を、ほかのタスクと同じように見て、直し、やめられる。
- 委ねてから始まるまでに間があるので、秘書は始まるのを待たない。
- 詰所は、委ねたタスクの状態と経過だけを Famulen の名で手帳に書く。働き手が書いたものは、秘書が読むまで手帳に入らない。
- 始めることへの主人の確認は残り、詰所が求める。
