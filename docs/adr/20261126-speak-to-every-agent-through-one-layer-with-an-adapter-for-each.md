# エージェントとは共通の操作とイベントでやりとりし、違いはアダプターが引き受ける

状態：採用

## 背景

委ねた仕事をするエージェントは Claude Code だけで、その起動の仕方と行の形を、仕事を動かす側がじかに知っていた。Codex や OpenCode も同じように動かすと、エージェントごとの違いが、順番を決める所、権限を裁く所、見せる所のそれぞれに入り込む。エージェントの形式には公開されていないものがあり、版が変わると変わる。

## 決定

仕事を動かす側は、エージェントとのやりとりを共通の操作（始める・続ける・送る・答える・割り込む）とイベント（発言・道具・問い・段取り・使用量・終わりなど、書いている途中のものを含む）だけで知る。エージェントごとのアダプターが、その起動と行を、共通の形との間で移す。

アダプターは権限を判断しない。できないことを黙って補わず、知らないものを黙って捨てない。知らない問いは断る。

## 検討した他の案

- 仕事を動かす側に、エージェントごとの分岐を書く。エージェントが増えるたびに、権限の判断を含むすべての所を直すことになり、守りの抜けを見つけにくい。
- ACP を共通の形にする。許可や再開の多くが任意で、Claude と Codex には別の作者の変換層が挟まる。
- 端末の画面を読む。状態を取り違えて、承認の画面に打ち込むおそれがある。

## 結果

- エージェントを足すことは、アダプターを足すことになる。どのアダプターにも同じ適合テストを通す。
- 仕事が求めることのできないエージェントでは、その仕事は始まらない。
