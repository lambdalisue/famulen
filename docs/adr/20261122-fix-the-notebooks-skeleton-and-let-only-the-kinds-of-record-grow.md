# 手帳の骨組みは決めておき、増やせるのは記録の種類だけにする

状態：採用

## 背景

手帳は、道具がなくても AI が読めば分かるように書く。どの手帳でも同じ場所に同じものがあれば、AI も道具も手帳ごとの説明を読まずに扱える。記憶の層には、毎回読む・夢が整理する・戻せるといった振る舞いが結びついていて、層を手帳ごとに作れると道具が前提を持てない。一方で、何を記録したいかは手帳の持ち主によって違う。

## 決定

手帳のディレクトリの形は決めておき、持ち主が増やせるのは記録の種類だけにする。記録の種類の欄は、その種類のディレクトリの README に宣言する。

## 検討した他の案

- ディレクトリを自由に足させ、形をすべて手帳の README に宣言させる。手帳ごとに設定が要り、AI は宣言を読むまで何がどこにあるか分からない。
- 記録の種類も決めておく。持ち主が要る記録を置けず、決まった種類に無理に押し込むことになる。

## 結果

- 手帳を作るとすぐに、決まった層と標準の記録の種類が揃う。
- 決まった場所にないファイルは、道具が検査で知らせる。
- README は説明で、記憶や記録そのものは README に書かない。
- 手帳の README の frontmatter は、手帳の形の版だけを持つ。
