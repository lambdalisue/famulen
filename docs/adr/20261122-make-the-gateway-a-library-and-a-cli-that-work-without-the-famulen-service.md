# ゲートウェイは Famulen のサービスなしで使えるライブラリと CLI にし、Famulen はライブラリを使う

状態：採用

## 背景

ゲートウェイは、外のサービスへのつなぎ方・秘密・呼び出しの可否・呼び出しの控えを一か所に持つ。外への呼び出しをどこから来ても同じ決まりで裁くことは、Famulen の秘書に限らず、持ち主がほかの AI やスクリプトから外を呼ぶときにも役に立つ。ゲートウェイが Famulen のサービスの中にあると、サービスの外では秘密を手で配るしかなく、呼び出しも控えに残らない。

## 決定

ゲートウェイは、Famulen から独立したライブラリ（`famulen-gateway`）として持ち、Famulen はそのライブラリを使う。ライブラリの上に、持ち主がつなぎ先を足し、ログインし、金庫に秘密を入れ、道具を呼べる CLI（`famulen-gateway-cli`）を持つ。

## 検討した他の案

- ゲートウェイを Famulen の中に置いたままにする。ゲートウェイの決まりを使うのに Famulen のサービスが要り、ほかの AI やスクリプトからは使えない。
- ゲートウェイを、ほかのプログラムがネットワーク越しに呼ぶサービスにする。呼ぶ者を確かめる仕組みと、公開する入口が要る。持ち主 1 人の手元では重い。

## 結果

- ゲートウェイのライブラリは、秘書・見張り・手代・手帳・ワークグループを知らない。呼ぶ者は名前で名乗り、どの呼ぶ者に何を許すかは、使う側がゲートウェイに渡す。
- つなぎ先・権限・金庫・控えは、ゲートウェイが自分の置き場所に持つ。
- ゲートウェイは、届いたものに手を加えず、つなぎ先ごとに決めた宛先へ渡すまでを持つ。届いたものの意味を読むのは使う側。
- CLI から呼んでも、Famulen から呼んでも、同じ権限で裁かれ、同じ控えに残る。
