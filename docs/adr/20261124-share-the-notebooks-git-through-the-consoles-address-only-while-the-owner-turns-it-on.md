# 手帳の Git は、主人が有効にしているあいだだけ、コンソールと同じ口から出す

状態：採用

## 背景

主人は、ほかのマシンの AI にも、秘書や夢と同じ手帳を読み書きさせたい。ファイルを上書きする同期サービスでは、片方の変更が失われる。コンソールには私的なネットワークの中から届き、届いた人は今でも手帳を書き換えられる。

## 決定

手帳の Git は Famulen 自身が HTTP で出し、コンソールと同じ番地からだけ届くようにする。出すのは主人が有効にしているあいだだけで、入れる人の範囲はコンソールと同じにし、Git だけのログインは持たない。push で変わったファイルが手帳の決まりから外れて誤りになるときと、履歴を書き換えるときは、受け取らない。

## 検討した他の案

- SSH で出す。待ち受けと、鍵と、シェルに入れる利用者が増える。
- 手帳に、マシンごとのトークンを求める。コンソールの口から同じことができるので、穴は減らず、ログインの仕組みだけが増える。
- Tailscale が知らせるログイン名で絞る。Famulen が Tailscale に依存し、同じマシンのプログラムはその名前を偽れる。
- Famulen の外に bare のリポジトリを置き、Famulen もそこへ push する。受け口のプログラムと、止まったときの食い違いが増える。

## 結果

- コンソールに入れる人は、有効にしているあいだ、手帳の履歴まで丸ごと読める。
- ほかのマシンの AI は心得も書ける。書いたものは秘書に効く。
- 誰が書いたかは、コミットの作者と trailer による自己申告になる。
- push は、秘書や夢の書き込みと順番に手帳に入る。
