# 仕上げで外へ出る操作は Famulen が行い、エージェントには鍵を渡さない

状態：採用

## 背景

直接の仕事は作業場所の中に閉じていて、push、PR、マージ、反映は主人か Adroit のセッションの手に残っていた。エージェントに頼むには、GitHub の鍵と、囲いの外へ届く手を渡す必要がある。エージェントは他人の書いた文を読み、自分の書いたコードを動かすので、渡した鍵の使われ方は保証できない。

## 決定

直接の仕事の仕上げは Famulen が段として持ち、push、PR、マージ、反映は Famulen が主人の鍵で行う。エージェントの番は実装と手直しだけで、番が終わってエージェントを止めてから、外へ向かう操作をする。

- 外へ出してよい範囲は、主人がリポジトリごとに設定ファイルで決める。決めがないリポジトリでは、外へ何もしない。範囲は仕事を始めたときのものをその仕事に固定し、仕事の側からは変えられない。
- 出すのは、検査とレビューを通った中身だけ。マージするのは、CI が通ったのと同じコミットだけ。中身が変われば検査からやり直し、レビューの回数が残っていなければ出さない。
- 作業場所の参照、フック、置き換えはエージェントが書けるので信じない。相手先と土台は始めに固定し、中身は id で指す。
- 検査はエージェントが書いたコードを動かすので、ネットワークも鍵もない囲いの中で走らせる。
- 反映はマージしたコードを囲いなしで動かすので、Famulen 自身のリポジトリに限る。取るのは、固定した相手先の、マージされたコミット。
- レビューは、書いたエージェントとは別の、読むだけの実行が行う。

## 検討した他の案

- 対象を絞った鍵をエージェントに渡す。絞った鍵でも、検査やレビューを通らない中身を出せ、何を出すかを Famulen が照らせない。
- 外へ出る操作ごとに、エージェントの呼び出しを主人の確認にする。主人が決めた範囲の仕事でも、答えるまで進まない。
- 仕上げを Adroit のセッションに任せ続ける。直接の仕事が終わりまで通らない。
- 段取りをモデルへの指示とスキルに任せる。通ったかどうかが、エージェントの言葉でしか分からない。

## 結果

- エージェントに GitHub の鍵を渡さずに、PR の作成とマージが通る。
- エージェントは相手先から取り直せないので、手元のリポジトリが知る本流は Famulen が相手先に合わせる。
- 反映するコマンドはマージされた中身を主人として動かす。守りは、マージまでの検査、レビュー、CI にある。
- ネットワーク、ポート、nix の常駐、ホームへの書き込みが要る検査は、手元の囲いでは通らない。そういう確かめは CI が持つ。
- 型にできない手順は、これまでどおり文で書き、エージェントは作業場所でできる分だけを行う。
- Famulen が止まると、反映の他の段は続きから行う。反映は二度走らせず、結果が分からなければ主人に伝える。
