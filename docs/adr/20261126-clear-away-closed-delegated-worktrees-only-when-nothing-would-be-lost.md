# 終わった委託の作業場所は、何も失わないと確かめられたものだけを Famulen が外す

状態：採用

## 背景

Adroit は、セッションを閉じてもワークツリーを残す。閉じたセッションを再開でき、書きかけの仕事を失わないようにするための決定で、Famulen はそれに従ってきた。委ねた仕事は人が始めるものよりずっと多く、ビルドの成果物を含む作業場所が溜まって、ディスクを使い切りかけた。

## 決定

委ねた仕事の作業場所は、タスクが終わり、セッションが閉じたあと、Famulen が外す。外すのは、何も失わないと確かめられたものだけで、確かめられないことは、失うものがあるのと同じに扱って残し、主人に知らせる。仕事のものであることは、Famulen が付けた名で見分ける。

セッションが残るあいだワークツリーを残すという Adroit の決定は変えない。閉じたセッションの再開は、作業場所がなくなったあとでは、その場所では続けられなくなる。

## 検討した他の案

- Adroit に、閉じたセッションのワークツリーを外させる。Adroit は、仕事が済んだかを知らず、主人が自分で始めたセッションのものまで外すことになる。
- 日数が経ったものを外す。書きかけのまま止まった仕事を失う。
- ビルドの成果物だけを消す。作業場所は溜まり続け、動いているビルドを壊さないための確かめは同じだけ要る。
- 片づけることを、仕上げの手順として働き手にさせる。働き手は自分の作業場所の中で動いていて、自分の終わりのあとを見届けられない。

## 結果

- 本流に、別の変更としてまとめ直されて入った仕事の作業場所は残り、主人が外す。
- 作業場所を使うプロセスを見られないところ（サンドボックスの中など）では、何も外れない。
- 片づけは、手元のリポジトリの本流を、そのリモートから取り直す。ゲートウェイは通らない。
