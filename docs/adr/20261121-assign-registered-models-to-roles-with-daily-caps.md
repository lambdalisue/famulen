# 使えるモデルを登録し、役割ごとに 1 日の上限とともに割り当てる

状態：採用

## 背景

秘書、夢、見張り、トリアージ、見極め、声の聞き取りでは、要る賢さと量がまるで違う。主人は定額のサブスクリプション、ローカルの LLM、従量課金の API を使い分けたい。従量課金を選ぶことは少ないが、選べないのは困る。使った量と額も見たい。

## 決定

主人は使えるモデルを種類（エージェント CLI・ローカル・API・判定 API・文字起こし）とともに登録し、役割ごとに 1 つを割り当てて 1 日の上限を決める。秘書にはエージェント CLI だけを割り当てられる。Famulen は呼び出しのたびに使った量と見積もりの額を記録する。

## 検討した他の案

- すべてを秘書のモデルで行う。見張りの量では予算が持たない。
- 従量課金のモデルを使えないようにする。主人が選べる道を狭める。

## 結果

- 上限に達した役割は、その日のそれ以上の仕事を後回しにする。
- 使った量と額は、モデルごと・日ごとに画面で見られる。
