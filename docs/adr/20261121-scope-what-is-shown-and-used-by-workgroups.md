# 見せるものと使うものを、主人が決めるワークグループで絞る

状態：採用

## 背景

主人は、ぶち抜きで頼みたいときもあれば、仕事だけ、個人だけのつもりで頼みたいときもある。仕事のときに個人の予定やアカウントを使われては困るが、空いていない時間は知っていてほしい。

## 決定

主人はワークグループ（仕事・個人など）を自由に足し消しでき、チャネル・つなぎ先・見張りをそれぞれに入れる。記録と記憶にはワークグループの印を付ける。主人がワークグループを選ぶと、会話と画面はそこに入るものだけを使い、見せる。「すべて」は全部を使う。会話はワークグループで分けず、発言ごとに添える。

## 検討した他の案

- ワークグループごとに秘書や会話を分ける。ワークグループをまたぐ話が通じず、同じことを何度も教えることになる。
- Slack のワークスペースのようにアカウントだけで分ける。記録や記憶を分けられない。

## 結果

- ほかのワークグループの予定は、主人が決めたとおりに、薄く出すか出さない。予定を入れるときは、どちらも避ける。
- ワークグループごとに、使うアカウントとテーマの色を決める。
- ワークグループに入らないつなぎ先を使うときは、確認してから使う。
