# 設定はコンソールで変え、データベースに保存する

状態：採用

## 背景

主人はチャネル・つなぎ先・モデルなどの設定を、ファイルや環境変数に書くより画面で選びたい。Famulen は常駐するので、設定のたびに起動し直すのは手間が大きい。一方で、待ち受け先やデータの置き場所のように、動き始める前に決まっていなければならないものがある。金庫の鍵のように、Famulen の中に残してはいけないものもある。

## 決定

設定はコンソールで変え、Famulen のデータベースに保存する。コンソールで決めた値は、環境変数と設定ファイルより優先する。動き始める前に要るものは環境変数か設定ファイルで、秘密は環境変数だけで渡す。Famulen は何も設定されていなくても起動し、設定が変わると関わる部分を組み直す。

## 検討した他の案

- すべてを設定ファイルで決める。変えるたびにファイルを直して起動し直す。

## 結果

- コンソールで変えられる設定については、環境変数と設定ファイルは最初の値を与えるだけになる。
- 秘書も道具を通して一部の設定を変えられ、その変更も同じ記録に残る。
