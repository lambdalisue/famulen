# 記憶と記録は、Famulen がなくても読める Markdown の手帳 1 つに持つ

状態：採用（結果のうち、夢が記録を書き換えず消さないとしたものは 20261128-let-the-dream-tidy-the-whole-notebook-whoever-wrote-it.md に置き換えられた）

## 背景

主人は、Famulen という仕組みがなくなっても、手元のディレクトリを AI に読ませるだけで主人を知る補佐役が得られることを望む。記憶と記録を別々の場所に分けたり、Famulen を通さなければ読めない形に置いたりすると、それができない。主人は Markdown を Arto で読む。

## 決定

記憶と記録は、1 つの Git リポジトリ（手帳）に、Arto で読める Markdown で持つ。記録の中身は、Markdown として読んで分かるように本文の構造で書き、frontmatter はメタデータだけに使う。つながりは wiki リンクに書き、手帳だけで読み方が分かるようにする。Famulen のデータベースには仕事を回すための状態だけを持ち、主人について知っていることは持たない。

## 検討した他の案

- 記録は SQLite に置く。並べ替えや期限で動くことは速いが、Famulen を通さないと読めず、主人について知っていることが二か所に割れる。
- 記憶も記録も SQLite に持つ。主人が中を読みにくく、Git の経緯も残らない。
- 記録の決まった欄も frontmatter に書く。道具は読みやすいが、Markdown として開いた人には、日時や相手のような中身が読み物から外れて見える。

## 結果

- 手帳を AI に読ませれば、Famulen がなくても主人のことが分かる。
- 記録の変更も、記憶と同じく Git に残り、戻せる。
- 並べ替えや絞り込みは、手帳から作った索引で行う。手帳と索引が食い違えば手帳が正しい。
- 夢は記憶を整理する。記録は、記憶に紛れたものを移し、することを書いたメモをタスクにし、古くなったかもしれないものに印を付けるだけで、書いてある事実を書き換えず、消さない。例外は物で、同じ注文の同じ品と確かに言える記録はまとめ、日が経った注文は届いたことにする。
- 鍵やトークンは手帳に入れない。
