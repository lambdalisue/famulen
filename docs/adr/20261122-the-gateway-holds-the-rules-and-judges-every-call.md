# 権限の決まりはゲートウェイが持ち、ゲートウェイがすべての呼び出しを裁く

状態：採用

## 背景

外への呼び出しの可否は、呼び出しが通る道ごとに決めると抜け道ができる。秘書の道具だけを裁き、見張りやほかの口からの呼び出しを素通りさせると、同じ道具を別の口から呼べば権限を超えられる。ゲートウェイは外への唯一の口で、呼び出しはすべてそこを通る。

## 決定

道具の権限（自動・許可・確認・禁止）の決まりはゲートウェイが持ち、ゲートウェイが呼び出しのたびに裁く。呼び出しは、誰のためのもの（持ち主）と、誰が呼んだか（呼ぶ者）を持ち、呼ぶ者ごとの付与は権限より広くできない。確認の権限の呼び出しは保留の札を返し、持ち主に尋ねるのは使う側がする。

## 検討した他の案

- 権限は使う側（Famulen）が持ち、ゲートウェイは通すだけにする。ゲートウェイを直接使えば権限を通らず、CLI やほかのプログラムには権限が効かない。
- 確認もゲートウェイが持ち主に尋ねる。ゲートウェイがコンソールや Slack のチャネルを知ることになり、使う側ごとの尋ね方を選べない。

## 結果

- どの口から呼んでも、同じ権限が効く。
- 呼ぶ者ごとに道具を絞れる。何も付与されていない呼ぶ者は、何も呼べない。
- 承認は、同じ中身の呼び出しを 1 回だけ通す札になる。
- 呼び出しの控えには、持ち主と呼ぶ者の両方が残る。
