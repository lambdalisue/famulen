# 夢は、だれが書いたものでも、手帳全体をまとめ・直し・消して整える

状態：採用（20261121-keep-memory-in-layers-of-markdown-in-git-and-reorganize-it-in-a-nightly-dream.md の、夢は小さな変更だけを当てるとした決定と、20261122-keep-memory-and-records-in-one-markdown-notebook-that-reads-without-famulen.md の、夢が記録を書き換えず消さないとした結果を置き換える）

## 背景

夢は記憶を整えるものとして作り、記録には印を付けるだけで、書いてあることを書き換えず、消さないことにしていた。記憶でも、主人の言ったことは、主人が訂正するか多くの根拠がそろうまで直さず、一晩でファイルを半分より小さくしなかった。そのため、明らかに同じ物が別の記録として並び続け、古くなった記録も印が付くだけで残り、手帳は読むたびに確かめなければならないものになっていた。

手帳は Git にあり、夜ごとの変更は一つのコミットになる。夢がまとめ・直し・消しても、前の版はいつでも履歴から読め、戻せる。

## 決定

夢は、記憶と記録を一つの手帳として整える。確かだと言えるときは、主人が書いたものも含め、同じことの記録や記憶を一つにまとめ、誤りや古くなったところを直し、何も言っていないものを消す。主人に尋ねるのは、どう直せばよいか分からないときだけにする。

## 検討した他の案

- 記録は今のまま印を付けるだけにし、主人に整理を任せる。主人が手を入れない限り重なりも古さも残り、手帳を頼れない。
- 夢はまとめ・直す案を出し、主人が認めたものだけを当てる。主人の手間が残り、尋ねることがたまるほど整理が進まない。
- 夢が書いたものだけを整え、主人が書いたものには触れない。重なりの多くは、主人の書いたものと夢や道具が書いたものの間にあり、それが残る。

## 結果

- 手帳の重なりと古さは、夜ごとに減る。主人は確かめる代わりに、Git の履歴で何が変わったかを読み、要らない変更を戻す。
- 主人の書いたことや言ったことも、夢が言い直し、まとめ、忘れることがある。主人が残したいことは、言い直されても意味が残るよう、夢に伝わる言葉で言う。
- 夢の誤りは、尋ねる手前で止まらず手帳に入る。誤りに気づくのは、夜ごとの変更と履歴を読んだときになる。
