# すべての入力を、差し替えられるモデル CLI の常駐セッション 1 つに渡す

状態：採用

## 背景

Famulen は自前のエージェントループを持たず、既存のモデル CLI の上に建てる。主人は Claude Code を使うが、いずれローカルの LLM などに替えたい。主人はチャネルがいくつあっても会話が一つであることを望む。

## 決定

主人の頼みごと、予定、起床予約、確認の答え、見張りが渡すもの、つなぎ先からの知らせは、すべて常駐する 1 つのセッションに入力として渡す。セッションを動かすモデル CLI は差し替えられる部品とし、Famulen はそれに道具（MCP）と権限の判定を渡す。部品は Claude Code 1 つを持つ。

## 検討した他の案

- Claude Code を決め打ちにする。ほかのモデルに替えるとき、道具・権限・記憶の扱いを作り直すことになる。
- チャネルやワークグループごとにセッションを分ける。会話と記憶が割れ、「来週の空き」のようにワークグループをまたぐ話が通じない。

## 結果

- 道具は MCP で渡すので、どのモデル CLI でも同じ道具と権限を使える。
- Famulen が再起動しても、同じ会話を再開する。
- 夢や見張りのような、会話ではない仕事は、このセッションとは別に動かす。
