# 毎回の会話に渡す機密の記憶は、会話の印にせず、そこから外や手帳へ出るものを見極めに照らして読ませる

状態：採用

## 背景

心得、夢を待つ主人の言葉、長期記憶の索引、作業記憶の題名は、会話を始めるたびに秘書に渡る。その中には機密を読んで書いた行がありうる。秘書がそれを読んだかは、道具の呼び出しに残らない。

## 決定

渡る記憶の印のある行は、会話の印にはしない。ほかの人に届くもの（発言と、つなぎ先の道具で送る内容）と、ターンが手帳に書いたものを読む見極めのモデルに示し、その内容を伝えるものだけを、確認にするか印を付ける。示す行には、いまの記憶の行に加えて、その会話に渡したことのある行を含める。続いている会話は、夢が記憶から消した行を持ち続けるため。

何も読んでいないターンのつなぎ先への送信は、示した行を伝えるかだけを読ませる。発言のような、人の評価や公開でないやりとり一般は問わない。

## 検討した他の案

- 印のある行が渡った会話に印を付ける。印のある行が一つでもあれば、すべての会話のすべての発言と送信が確認になる。
- 印のある行を渡さない。秘書が主人の決まりを守れなくなる。
- つなぎ先への送信は見極めに読ませない。心得に写った機密が、メールや公開の投稿で確認なしに出る。
- 手帳への書き込みは見極めに読ませない。心得の機密を別の記憶や定期の仕事に写すと、印のないまま外へ出る。

## 結果

- 普通の返事や送信の確認は増えない。
- 機密の行がある間は、手帳に書いたターンのあとに、見極めを呼ぶ。
- 言い換えやほのめかしを見落とすかは、見極めのモデルの判断による。
