# 主人と話し手帳を書くのは秘書だけにし、見張りと手代は仕事ごとに決めた範囲を読むだけにする

状態：採用

## 背景

秘書 1 人では、外から届く大量のものを読むことと、時間のかかる仕事を並べて進めることが同時にできない。一方で、手帳には主人の機密も入る。外の文面を読む役や使い捨ての働き手が手帳を自由に読み書きできたり、広い道具を持ったりすると、届いたメールに書かれた指示で手帳の中身が外へ出たり、誰が何を覚えたのか分からなくなったりする。それでも仕事には、頼みに書き写しきれない手帳の中身を、自分で引いて読みたいものがある。

## 決定

Famulen の中で、主人と話し、手帳を書くのは秘書だけにする。見張りと手代は手帳に直接触れない。読めるのは、その仕事のために決めた範囲を、Famulen の道具を通してだけ。見張りは外から届いたものをふるって秘書に知らせるだけで、道具を持たない。見張りが読んだものから書き出した人についての気づきだけは、Famulen が、他人の文面から推し量ったという印を付けて気づきに書く。委ねられた仕事の働き手は仕事ごとに生まれ、渡された道具だけを使い、結果を秘書に返す。手帳に書きたいことは案として出し、秘書が確かめてから書く。秘書が名指したものより広く読むことと、案を出すことは、仕事ごとに主人が許す。

## 検討した他の案

- 秘書がすべてを一人でする。見張りの量で秘書の会話が埋もれ、長い仕事のあいだ主人に応じられない。
- 見張りと手代にも手帳を丸ごと読ませる。仕事に要らない機密まで、外の文面を読むモデルの前に置くことになる。
- 手帳のファイルを写して、働き手の場所に置く。渡したあとに仕事を止めても読め続け、読んだことも分からない。
- 働き手にも手帳を書かせる。外の文面が手帳を書き換えられ、手帳を書く者が増えて経緯を追えなくなる。
- 見張りと手代にも秘書と同じ道具を渡す。外の文面が道具を動かせてしまう。

## 結果

- 手帳の何を見張りと手代に見せるかは、秘書と主人がその時々に決める。
- 主人に関わらないやりとりからも、人となりを知れる。書き手の言葉がそのまま決まりになることはなく、人についての事実として夢が選ぶ。
- 外から届いた指示は、秘書が読んで判断するまで手帳を何も変えない。
- 手帳の変更は、秘書と、主人と、人についての気づきを書き留める Famulen と、主人が手帳を渡した Famulen の外の AI のものだけになる。
- 読む範囲の判定は Famulen が持ち、検索の結果やリンクからも範囲の外を返さない。
- 働き手が主人に確認を求めるかは、仕事ごとに決まる。
