# エージェントは、仕事ごとの別プロセス（実行役）の下で動かす

状態：採用

## 背景

委ねた仕事をするエージェントは Famulen の子プロセスで、Famulen が動き直すと途中で切れていた。Famulen はよく動き直すので、長い仕事ほど最後まで届かなかった。

## 決定

エージェントの親は Famulen ではなく、仕事ごとに一つ始まる小さなプロセス（実行役）にする。実行役はエージェントを知らない。プログラムを始め、その書いたものと書き込まれたものを通し番号で残し、鍵を持つ者に渡す。Famulen が止まっていても仕事は続き、Famulen は動き直すと続きから受け取る。

実行役とは、そのディレクトリの中の、本人だけが開ける口で話す。ポートは開かない。

実行役は、始めたときの版のまま仕事の終わりまで動く。Famulen と実行役の版が違って話が通じなくても、仕事を止めることと、終わった仕事の記録を読むことは、いつでもできる。

## 検討した他の案

- すべての仕事の親になる、常駐する一つの実行役を置く。新しい版に入れ替えるには、動いている仕事を切るか、すべてが終わるのを待つことになる。一つが落ちるとすべてが切れる。
- エージェントの会話を再開する。再開できるのはターンの切れ目だけで、切れたときに動いていた道具がどこまで済んだか分からない。
- エージェントの出力をファイルに向け、親なしで動かす。問いに答える口がなく、長さの限りを守らせる者も、始めたプロセスをまとめて止める者もいない。

## 結果

- Famulen を動き直しても、仕事は切れず、出力も問いも欠けない。Famulen が止まっているあいだの問いは、動き直すまで待つ。
- 実行役が落ちるか、マシンが動き直すと、仕事は切れる。
- 仕事が動いているあいだ、Famulen は、その仕事を始めた版の実行役と話せなければならない。
- Famulen を動かす仕組みが、Famulen とともに子のプロセスまで止めると、仕事も切れる。
