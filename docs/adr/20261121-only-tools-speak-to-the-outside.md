# 外へ出るのはツールを通したものだけで、モデルの最終テキストは外に出さない

状態：採用

## 背景

一つのセッションが、主人への返事、見張り、予定の入力をまとめて受ける。見張りや予定の多くは「知らせることはない」で終わるべきで、そのたびに何かが投稿されては困る。どの返事をどこへ送るかも、入力によって違う。

## 決定

コンソールや Slack への返事を含め、外へ出るものはすべてツールの呼び出しとして起こす。モデルが最後に書くテキストは、どこにも送らない。

## 検討した他の案

- 最後のテキストを、入力の来た場所へ返す。黙っているべき見張りでも何かが投稿され、どこへ返すかを Famulen が推し量ることになる。

## 結果

- 何も呼ばずに終わったターンは、何も外に出さない。
- 返事の宛先は、モデルがツールの引数で指定する。
- 外へ出たものは、すべてツールの呼び出しとして記録に残る。
