1. `AGENTS.md` のとおりに書けているかを確かめ、`just ci` を通す。コンソールに見えるものを変えたなら `just e2e` も通す。
2. `main` からの差分をレビューし、指摘がなくなるまで直す。使えるレビューのスキルがあれば使う。
3. 一つの意図につき一つの PR を作る。push してよい。
4. CI を見張り、どれか一つでも落ちたら、ほかのジョブを待たずに原因を調べて直し、push し直す。`main` とぶつかったら、最新の `main` に載せ直す。
5. CI がすべて通ったらマージする。マージしてよい。マージする権限がなければ、PR の URL を伝えて終える。
6. このマシンの Famulen がこのリポジトリのチェックアウトから動いていれば、最新の `main` を反映する。してよい。そうでなければ飛ばす。
   - 先に、同じリポジトリで動いているほかのセッションに、動かし直すことを知らせる。
   - 動いているチェックアウトに手を付けかけの変更があれば触らず、そのことを伝えて終える。
   - ビルドに失敗したら動かし直さない。
   - バックエンドの `/health` とコンソールが応え、変えたことが効いていることを確かめる。
