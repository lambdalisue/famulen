# RSS をつなぐ

公開の RSS・Atom のフィードを読む。アプリの登録も、ログインも鍵も要らない。

- 1 つのつなぎ先が 1 つのフィード。フィードの URL（ブラウザで開くと XML が出るもの。サイトの頁の URL ではない）を、`https://` から、末尾の `/` や `?` の後も含めてそのまま入れる。読むフィードごとにつなぎ先を足す。
- 秘書に頼んでも足せる。秘書が足せるのは `https://` の公開の URL だけで、足す前に確認が出る。
- 例：GitHub のリリースは `https://github.com/rust-lang/rust/releases.atom`、RustSec は `https://rustsec.org/feed.xml`。
- 道具は、フィードの XML をそのまま返す `get_feed` と、記事の頁を返す `get_page` で、どちらも読むだけ。
- `get_page` は、フィードと同じホストの、文字の頁だけを読む。別のホスト（`www.` の有無が違うものも）と、そこへのリダイレクトは断る。
- 認証の要るフィードは読めない。URL は秘密として扱わないので、鍵の入った URL は入れない。
