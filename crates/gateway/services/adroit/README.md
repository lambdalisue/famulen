# Adroit をつなぐ

Famulen を動かすマシンの [Adroit](https://github.com/adroit-app/Adroit) で、Claude Code や Codex のセッションを始められるようにする。ログインも鍵も要らない。

- `adroit` コマンドが、Famulen を動かす環境の `PATH` にあること（`which adroit` で確かめる）。コンテナの中の Famulen からは使えない。
- セッションはあなたの Adroit に開き、あなたが見て、途中で口を出せる。ファイルの書き込みやコマンドをどこまで許すかは、そのエージェントの設定と Adroit の画面で決まる。
- 秘書はセッションを自分では始めず、タスクとして委ねる。始めるたびに、どのタスクで、どのディレクトリで何をさせるかを添えてあなたに確認する。セッションはあなたの権限で動くので、「許可する」に変えるときは気をつける。
- セッションがあなたを待つと、秘書が、何を尋ねているかを文脈とともに伝えに来る。Adroit が最前面にないか、1 分以上 Mac に触れていないか、画面をロックしていれば、すぐに来る。Adroit を見ているあいだは来ない（10 分待ったままなら来る）。知らせたあとに Adroit で答えると、Slack の確認は取り下げられ、知らせにももう要らないことが書き足される。
- 秘書は、あなたが始めたものも含めて、セッションの一覧と様子、やりとりを読める。続きを頼むときは、あなたの言葉ではなく Famulen からの依頼として届き、あなたに確認してから送る。
- 許可・計画・質問への答え、止める、終える、には鍵が要る。Adroit の設定の「General」で、外のプログラムに許して（`outside.steer`）鍵を作り、Famulen のつなぎ先の頁の「アカウントの値」に入れる。鍵は金庫に入る。
- 質問には、Slack かコンソールに出る選択肢のボタンか、自分の言葉で答える。それがそのまま届き、改めて承認することはない。
- 答えるたびに、問いの原文があなたに出る。長くて全文を読めない問いには答えられない。承認・却下したものだけが届き、「許可する」にしても尋ねずに答えることはない。鍵がないか、Adroit が外のプログラムに許していないあいだは答えられない。
- 一覧・様子・続きには、`adroit session list` のある版の Adroit が要る。
