# 手帳

ある人について知っていることを、Markdown で置いた手帳。このディレクトリを読めば、この人のことが分かる。変更はすべて Git の履歴に残る。

- `memory/`：やりとりから覚えたこと。まず [memory/README.md](memory/README.md) を読む。
- `records/`：この人が頼りにする事実。種類ごとのディレクトリにあり、それぞれの README に読み方がある。
- `.notebook/`：手帳の道具の作業用。Git には入れず、消しても手帳から作り直せる。

記録の中身は、題名の下のリストと節に書く。先頭の YAML の frontmatter は、ID・ラベル・出どころなどのメタデータだけを持つ。手帳の中のほかのファイルへは `[[memory/core|心得]]` のような wiki リンクでつなぎ、記録へは `[[records/<種類>/<id>|題名]]` と書く。`Related` の欄には、関わる記録を種類を問わず並べる。鍵やトークンは書かない。
